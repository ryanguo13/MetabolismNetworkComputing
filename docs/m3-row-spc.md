# M3：线性隐式 SPC 预测器与三次慢驱动连续扩展

日期：2026-11-08。**M4 仍不准入。**本轮完成 280 条局部记录、300 个冻结线性配置和两组阶数诊断。三次驱动改善了连续输出正确性，但没有达到两模型、两原精度档、完整登记窗口、分裂覆盖至少 50%、7 次正式重复、中位加速至少 1.5 的原门槛。未实施 PE。

## 1. 为什么优先做这件事

[上一轮 SPC](m3-spc.md) 的完整 SDIRK 预测器需要多次非线性迭代，小模型预测成本已压缩了潜在收益。本轮先核对已发表的线性隐式 SPC：每宏步一次完整 Jacobian／LU、四次 RHS 和四次线性求解，再执行一次修改快流。完整 ROS34PW2 与成熟 Radau 都获得相同的合理优化机会。

这里的 MRI-GARK 属于用阶段系数和慢驱动函数满足加法耦合阶条件的多速率框架；它不是简单的 Lie／Strang 子流串接，也不是本项目从零提出的全新方法。本轮第一个构造直接采用文献示例；第二个三次连续扩展是从其一般框架推导的研究候选，尚未完成新颖性检索，不声称首创。

## 2. 原文、读到的内容及实现

Michael Günther、Adrian Sandu，*Multirate Linearly-Implicit GARK Schemes*，[arXiv:2102.10203v1](https://arxiv.org/abs/2102.10203v1)。读取引言、§2.3 阶条件、§8 式 8.1 预测器、§10 式 10.1–10.9 及 Example 8；不声称通读或核对所有系数表。PDF SHA、原文摘录及阅读深度见 `results/m3-row-spc/literature-reading.json` 和 `primary-excerpts.txt`；身份核验沿用此前独立的文献 provenance。

设完整 RHS 为 f=F+S，J 为完整冻结 Jacobian，L_s 为慢 Jacobian。ROS34PW2 的四个增量满足

```
(I − H γii J) ki = H f(y + Σj<i αij kj) + H J Σj<i γij kj
ks_i = H S(y + Σj<i αij kj) + H L_s Σj≤i γij kj
```

原文允许一般多项式 μ(s)，ν=0；修改快流为

```
v′(t) = F(v(t) + Ks μ(t/H)),  v(0)=y
yn+1 = v(H) + Ks b
```

Example 8 选择 μ(s)=μ1 s，μ1 对 1、c=α1、g=γ1 的矩分别为 1、1/3、0，保留一个自由参数。本轮登记 θ=0、0.5、1。转换 z=v+Ks μ 后，快积分为常量强迫，但 **z(H) 与最终物理终点相差 Ks(b−μ1)**。修改流收支必须用 z(H)，物理收支必须用最终物理曲线，二者分别审计。

`research/row_spc.py` 保留这一原文构造，物理曲线先采用完整 RHS 端点 Hermite。全部实际阶段、快流接受状态、原始曲线极值和最终输出均检查；没有裁剪或参考轨迹注入。

## 3. 第一轮结果改变了下一步优先级

初始登记：两模型 × H∈{.001,.003,.01}，每模型三个快组阈值、三个 θ、两个内层容差；108 个候选、6 个完整 ROW、36 个成熟 Radau。150 次积分均完成，但 **108 个候选没有一个通过全部局部门槛**。积分完成不等于误差／保护合格，失败评分和非正物理输出均保留。

解析线性映射、全快／全慢极限和终点修正收支测试通过。非线性两状态例在 θ=.5 有粗网格抵消：N=8 到 16 误差反而上升，N=64 观测阶 2.765，最初要求 >2.8 的测试失败。保留初始测试源码及结果后，将网格延伸至 128、256，阈值不变；θ=0、.5、1 的最后观测阶为 2.990、2.949、2.997，完整 ROW 为 2.993。不能仅凭粗网格的偶然高阶或低阶判定方法。

初始登记引用的测试源码已保存为 `initial-test-source.py`；`test-revision.json` 记录旧 SHA、现 SHA 和唯一的网格范围变更。核验器对原登记检查归档的原源码，对新诊断检查新源码。数值内核、原始登记和所有运行数据没有重写。

对实际小模型早／晚状态的 300 个精确快积分冻结线性映射，有 298 个谱半径筛查通过。这个结果不证明非线性稳定性；它说明不能把本批失败一概归因于谱失稳。

大模型 H=.001 的一个候选：终点净通量归一化误差约 .034，而 Hermite 输出最大值约 229；完整 ROW 终点约 9.78e−5，Hermite 输出约 14.82。小模型也有终点误差，不能仅归咎于输出。下一步因此从继续缩小线性解残差，转向与终点一致的慢驱动连续扩展。

## 4. 三次慢驱动的推导与范围

设 B=α+γ，e=B1，c=α1。取

```
μ(s) = M[:,0] s + M[:,1] s² + M[:,2] s³
[ 1ᵀ    ]      [1  0    0  ]
[ eᵀ    ] M =  [0  1/2  0  ]
[ (c²)ᵀ ]      [0  0    1/3]
[ (Be)ᵀ ]      [0  0    1/6]
```

对自主光滑系统、精确完整及分区 Jacobian，慢增量的展开是

```
ks_i = H S + H² e_i S′f
       + H³ [½ c_i² S″(f,f) + (Be)_i S′Jf] + O(H⁴).
```

因此 Ks μ(s) 匹配真实慢作用累计积分到三次项。这里是非刚性 Taylor 阶说明，误差常数依赖导数；不是统一刚性阶、任意近似 Jacobian 下的连续阶或非负性定理。

系数矩阵满秩，条件数约 117.4。基方法的三阶条件给出 μ(1)=b（数值误差约 5e−15），且另行验证积分 μ 与 c、g 的矩分别为 1/6、0，满足文献三阶 ROW 端点耦合条件。于是

```
z′(t) = F(z(t)) + Ks μ′(t/H)/H, z(0)=y, yn+1=z(H)
```

无终点跳跃。修改快流的分段三次曲线成为**待独立核验**的物理输出；不能仅凭该代换就宣布物理收支合格。完整 ROW 对照也使用相同的三次阶段扩展 `y+K μ(s)`。

实现为独立的 `research/row_continuous.py`，没有改写初始内核。新增测试核对矩条件、整个线性曲线的矩阵指数解、全快／全慢极限，以及非线性终点和连续输出的三阶收敛。实际模型的导数及浮点误差仍通过完整 ODE 对照审计。

## 5. 正确性改善，但总成本仍不够

36 个三次候选、6 个完整 ROW、36 个成熟 Radau 全部完成；候选通过宽／严格开发档分别为 **32／30**。开发档仍是浓度／单向通量 1e−4、1e−6，大模型净通量 1e−4，池／两类收支 1e−10。它们不替代历史冻结的原正式精度档。

大模型 H=.01 宽档最好比值 .971，仍低于 1。H=.001/.003 同实现完整 ROW 也更快：完整 ROW／候选约 .719/.650。所有基线采用相同状态、观察网格与保护，Radau 比较自动及整步起步、三个容差。

选择的严格档候选中，小模型预测器约 .88–.89 ms，总耗时约 2.58–3.22 ms；大模型预测器约 5.56–6.16 ms，总耗时约 10.71–15.03 ms。六者快流均只接受一步，但仍需快矩阵分解和保护开销。不能将一次内层接受步等同于没有成本。

进一步冻结内核补查 H=.03/.1：24 个候选、4 个完整 ROW、24 个成熟 Radau，全部完成，**候选均不合格**。小模型物理收支残差约 5e−9 至 5e−6，超过 1e−10；大模型最包含快组在 H=.03 的严格浓度误差约 13.7、净通量约 8.24，也超标。收紧内层容差不能消除这些宏步误差。此次扩大宏步未产生晋级依据。

## 6. 当前最值得继续的工作

追加六组 cProfile 热点诊断：每模型 H=.003 的最快严格候选、完整 ROW、成熟 Radau；小模型各 20 次、大模型各 5 次。端点与原记录一致。**这些带插桩的时间只用于定位热点，不是正式重复计时或加速证据**；不能相加有包含关系的累计时间。

- 小模型候选的模型速率计算累计约 1.48 ms／调用，物理收支约 .76 ms，梯度约 .47 ms。下一步优先验证重复速率评价能否共享：两类收支的公共 Gauss 节点可复用同一次完整速率求值，同时保留各自残差和加密积分检查。完整基线也应获得适用的同等优化。
- 大模型候选的稀疏 LU 累计约 6.23 ms／调用，占带插桩总时间约一半；完整 ROW 约 3.63 ms，成熟 Radau 约 7.60 ms。应优先研究可核验的分解复用／跨步缓存，而非只优化快 RHS。矩阵变化时不能冒称精确 LU 命中；陈旧 Jacobian 也不能自动沿用本节精确 Jacobian 的连续输出阶结论，必须先补查阶数、拒步回滚与累计误差。
- 若这些小规模成本实验没有两模型前景，再评估更高阶耦合是否能扩大合格宏步；目前不启动正式窗口重复或 PE。先有可靠的多步误差控制和端到端成本证据，再检验原 M4 准入门。

上述优先级来自本轮正确性与成本分解；并不预先断言缓存能带来 1.5 倍收益。独立完整 ODE 审计始终保留，所有失败均进入统计。
