### 本轮形成的判断

1. 从“无降阶分裂 → 有条件 PE”推进，比一开始混合所有近似更容易识别误差来源。
2. 动态快慢划分不是独立的新颖性；潜在贡献需围绕代谢结构、多守恒池、近似偏差控制及真实模型的净性能收益。
3. 小型模型负责正确性，中等规模真实动力学模型负责规模性能；模型是否真的适合分裂必须先测。
4. 任何加速结论均须在同实际精度下相对于稀疏隐式强基线成立，并计入分类、误差估计、PE 审计与回退成本。
