# M3：逐步累计缺陷估计与预算控制

2026-11-08。**M4 仍不准入。**本轮实现了真正跨宏步传播的误差状态，复用了预测器分解，发现并修复一类强刚性误差插值过冲，并开始带完整审计的扰动控制器测试。正确性保护与成本仍须分别成立；本轮没有满足原完整窗口、两模型／两原精度档、覆盖率、7 次重复及 1.5 倍加速门槛。

## 1. 问题与依据

[上一轮](m3-cached-row.md) 的 k-ecoli H=.003 路径有 16 个严格局部合格步骤，却出现累计浓度误差约 1.465 倍门槛。离线缺陷估计能抓到它，但成本高；误差状态逐宏步重置会丢掉历史，因此不是解决办法。

本轮采用自主完整系统 f 的缺陷方程

```
e′ = J_n e + f(P(t)) − P′(t)
```

其中 P 是候选的实际连续输出，J_n 是本宏步预测器已经计算的完整 Jacobian，两个细化分支都继承各自上一宏步的 e。它仍是线性化估计，不是已证明的误差上界；独立完整 ODE 审计不被替代。

## 2. 真正共享已有 LU

三阶段三阶 SDIRK 的公共对角 d 取 ROS34PW2 的 d=.4358665215084597：

```
A = [[d, 0, 0],
     [(1-d)/2, d, 0],
     [(-6d²+16d-1)/4, (6d²-20d+5)/4, d]]
b = A[2,:], c=A·1
```

直接核对 b·1=1、b·c=1/2、b·c²=1/3、b·A·c=1/6；测试负实轴放大因子和大负参数极限。这里不以有限测试代替整个左半平面的稳定性证明。

`linear_context_row.py` 保留冻结 ROWContinuous 的数值路径与保护，仅返回本次实际使用的 J、H、矩阵及求解句柄。若误差子步长度恰为 H，则它与预测器矩阵完全相同，可以直接复用。其他长度必须新分解，不能只因系数相似就标作命中。

原生快流的每个稠密输出段边界仍被尊重。登记了 1/2、2/4、4/8 三组子网格；其中 1/2 每宏步共享一次粗网格分解，但细网格仍需新分解。以 16 步路径计，分别需要 16、32、32 次额外分解，线性求解 144、288、576 次。没有隐藏重建 LU，也没有用旧轨迹重算因子后将该成本从“共享”中排除。

## 3. 误差输出的刚性过冲

第一版采用误差端点及误差方程导数构造 Hermite 输出。解析线性误差方程和渐近连续三阶测试通过，但真实强刚性路径上，误差导数会使区间内输出过冲。一个大模型末步的净通量评分约 304，而用相同误差节点的线性插值诊断约 .287。

第二版 `linear_error_output.py` 保持全部 SDIRK 节点与传递的误差端点不变，只改为分段线性误差插值。它避免导数驱动的插值过冲，**连续误差插值只有二阶**；三阶端点结论不能移植给这条线性曲线。两个独立子网格和原 `4×(central+refinement)` 评分保持不变。反例测试中，标量 e′=−10⁶e 的 Hermite 区间输出明显超过初始误差，线性插值保持在节点的凸包内。凸包性质不代表它一定包住真实误差。

两批各重放四条原候选路径／接受前缀，共 59 宏步、177 个网格配对评分、24 个不中断成熟 Radau 对照。两批合计 118 宏步、354 个配对评分、48 个对照。参考使用原标量完整 ODE，所有候选终点与冻结原始路径逐位一致。

| 输出版本 | 宽档错误接受 | 严格档错误接受 | 宽档保守拒绝 | 严格档保守拒绝 |
|---|---:|---:|---:|---:|
| Hermite 误差输出 | 0 | 0 | 91 | 98 |
| 线性误差输出 | 0 | 0 | 47 | 75 |

这些是关联的步骤／网格决策，不是独立统计样本；“未观察到错误接受”不构成可靠性保证。各版本都抓到已有累计严格失败；仍保守拒绝部分实际误差合格路径。Teusink H=.01 的 11 步前缀虽然误差评分可通过，其累计物理绝对缺陷约 3.54e−10，不能因此宣称通过 1e−10 收支门槛，更不能将未完成的原路径标为合格。

线性版本的两条大模型路径，1/2 网格估计约 .49/.52 秒，候选本身约 .20/.25 秒；更多细化更贵。复用一次 LU 的收益没有让估计器成为廉价控制器。这些是单次开发计时，运行中可能与验证进程重叠，不作正式性能或统计优势声明。

## 4. 事务、累计账本和前瞻测试

`StreamingDefect` 将误差分支端点、已接受浓度、历史最大评分和代次保存在状态中。试探不修改已接受状态，显式提交才推进；丢弃保持不变，重复／过期事务不能提交。离线强制诊断允许传播拒绝评分以观察后续行为，明确不把它称为实际接受覆盖；控制器只提交其规则和独立审计都通过的步骤。

累计账本将每个局部修改／物理残差和各自加密积分差换回共同初始分母，分别累加绝对值。这是保守的新增内部预算；最终仍直接计算真实累计物理收支。它不能被局部残差最大值代替，也不能靠正负抵消掩盖修改流缺陷。

两条预登记扰动起点：原 Teusink t=1、k-ecoli t=.1 前缀的第一个正浓度乘以 1.001，守恒池相对新初态计量；完整参考和全部对照使用同一扰动。目标短窗分别 .08、.024，最多 64 次尝试。候选每步最多保留 65 个均匀查询点并加原公共观测；每次尝试均做独立局部和从起点出发的累计完整 ODE 双容差审计。参考不参与步长建议；若建议接受但审计失败，停止并保存反例，不暗中按参考调步长。

第一种控制规则要求累计评分及账本预算不超过“已走时间／目标时长”份额；拒绝减半，预算占用低时增步 1.5 倍。结果：

| 模型 | 尝试／接受 | 目标窗完成比例 | 停止原因 | 审计否决的接受建议 |
|---|---:|---:|---|---:|
| Teusink | 64／48 | 3.63% | 尝试预算耗尽 | 0 |
| k-ecoli | 64／48 | .0282% | 尝试预算耗尽 | 0 |

最初大步确实超标；随后一些已满足原全程门槛的步骤仍被比例分配要求反复缩小，说明该额外分配规则过于保守。小模型第一步 H=.0003125 的实际严格误差约 .0168，评分 .0697、收支预算占用 .126，仍被比例分配拒绝。大模型初始层真实误差在一些缩步区间还非单调，不能假定使用固定误差阶指数就可靠。

据此登记第二种**总预算**对照：仍要求累计评分≤1、各累计账本≤1e−10；增步依据本次使用了多少剩余预算，拒绝仍减半。原全程门槛不变，比例分配只是内部控制器假设。该版本重复同一扰动起点，属于后续控制策略对照，不是新的独立留出验证。详细终态、尝试、拒绝、预算和计时见 `results/m3-streaming-budget/runs.json`；统一核验器逐次重建其决策。

总预算对照的实测结果：

| 模型 | 尝试／接受 | 目标窗完成比例 | 停止原因 | 审计否决的接受建议 |
|---|---:|---:|---|---:|
| Teusink | 41／23 | 5.83% | 最小步长；累计物理预算耗尽 | 0 |
| k-ecoli | 64／37 | 95.78% | 尝试预算耗尽；累计误差评分接近 1 | 0 |

小模型停在 t偏移=.0046643，累计绝对物理残差约 9.99999988e−11；已接受前缀的严格浓度误差约 .0442。大模型停在 t偏移=.0229870，最终拒绝提案评分约 1.000026，已接受前缀实际严格浓度／通量误差约 .1853。真实前缀精度尚合格不能推翻控制规则、忽略未完成部分或把 95.78% 写成完整窗口。

两种预算策略共 **233 次尝试、156 次接受、77 次拒绝**，四条算法路径均不完整，不能计算合格端到端加速。两批各 12 个成熟对照均覆盖各自计划的完整短窗。总预算版本的乐观成本约 .232／3.692 秒，加入独立局部／累计审计后约 2.28／118.02 秒；不是候选正式性能。局部独立完整 ODE 审计与累计独立审计没有因为成本高而被移除。

## 5. 当前结论与下一步

本轮把“累计误差不能清零”落实为可执行状态、双网格诊断与拒步回滚，也揭示了连续误差插值和预算分配的两种独立问题。它仍未解决总成本，且控制器失败不能通过增加运行次数或把未完成前缀标为成功来绕过。

后续优先检查预算耗尽前的预留／回退重算，并评估高阶慢驱动能否降低每宏步的物理收支缺陷、扩大有效宏步。涉及初始层时，完整系统启动的耗时和非分裂区间必须如实计入。只有同时具备全路径正确性和端到端效率前景，才进入原完整窗口、原精度档和正式重复；PE 仍未启动。
