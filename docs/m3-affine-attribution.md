# M3：真实分区的冻结仿射误差归因

2026-11-08。**下一优先级是改善慢预测轨迹的刚性精度，并同时检查小模型的非线性物理收支。** 本轮为机制诊断，不是效率验证；M4 原完整窗口、两模型／两原精度档、分裂覆盖率至少 50%、七次正式重复及相对最快合格成熟基线中位加速至少 1.5 倍均未满足。

## 1. 诊断设计

沿用 Rodas 仿射中心变量版本的两个真实起点、固定反应分组和 H=.001/.003/.01/.03；六／九阶段及完整／多速率两模式，共 32 个冻结候选，与已有 32 个非线性候选配对。多速率内层容差为 1e-10。历史失败和结果不改写。

对每个起点 y₀，构造逐反应的仿射速率

```
vL(z) = v(y₀) + Dv(y₀)(z-y₀),   fL(z) = S vL(z).
```

保留同一化学计量矩阵、组、依赖、尺度及安全检查。该系统只作诊断，不代替真实非线性 ODE，也不假定线性化保留一般化学正性。本批参考采样未发现负仿射速率。

独立完整非线性参考使用既有双容差审计。仿射参考在位移坐标上以完整稀疏 Radau 计算，容差 1e-12／1e-11，再与原状态坐标的独立 CVODE 双容差参考交叉比较。八组参考预算及跨方法差异全部小于严格门槛的 .05。另用独立位移代数重算预测器，保持它产生的慢驱动不变，以双容差 Radau 精确积分冻结快方程；这 16 个快流 oracle 不使用真实参考轨迹驱动候选。

采用同一个非线性参考尺度计算有符号 E_N、E_L 和 E_N−E_L。恒等式 E_N=E_L+(E_N−E_L) 不能转成三个无穷范数相加，也不能解释成因果贡献百分比。非线性真解与仿射真解之差另记，不能当作候选误差。

## 2. 大模型：线性机制已经足以重现主要浓度失败

九阶段多速率的浓度误差，单位为开发严格门槛：

| H | 非线性 E_N | 冻结 E_L | 差向量的无穷范数 |
|---|---:|---:|---:|
| .003 | .001209 | .001276 | .000876 |
| .01 | .462802 | .462217 | .030807 |
| .03 | 71.959244 | 71.588715 | 1.692032 |

H=.03 的两误差向量余弦为 .9997804。最大非线性误差位于物种索引 110、查询索引 59（均从零计数），其有符号非线性／冻结误差分别为 −71.95924／−71.58872；非活跃坐标也有约 32.93 倍误差，说明仅调整快坐标不足。

同一慢驱动下精确快流的浓度误差仍为 71.588692，实际快积分与该 oracle 的浓度差只有 .000261 倍门槛。通量／净通量差分别约 .103244／.001052 倍；不能笼统说所有观测的内层误差都可忽略。

同等九阶段完整 Rodas 的非线性／冻结浓度误差也分别为 68.2814／64.5707。因此证据支持优先改进上游预测器及其连续刚性近似，而不是继续收紧快积分容差。此结果不单独区分全部线性模态和连续插值机制，也不是其他多速率格式不可能有效的证明。

## 3. 小模型：物理收支仍需独立解决

H=.03 九阶段多速率的非线性／冻结浓度误差约 .30151／.37447，均已低于严格浓度门槛，余弦仅 .53947。精确快流仍得到约 .37447 的冻结浓度误差。

以 Gauss16／32 独立积分归一化有符号物理收支，记 NN 为非线性场在非线性候选曲线上的结果，LL 为仿射场在仿射曲线上的结果；NL、LN 为交叉评价：

| 量 | 有符号归一化残差 |
|---|---:|
| NN | 7.5761455e-10 |
| LL | 1.0593355e-10 |
| NL | −6.8643097e-6 |
| LN | 6.9354477e-6 |
| NN−LN（固定曲线换场） | −6.9346901e-6 |
| LN−LL（固定场换曲线） | 6.9353418e-6 |
| NN−LL | 6.5168100e-10 |

恒等式 NN−LL=(NN−LN)+(LN−LL) 的两项强烈抵消。16／32 点求积差约 1e-18，无法把失败归咎于求积精度；也不能把两项直接转换为因果比例。NN 和 LL 均超过 1e-10 的原物理收支门槛，线性预测器改善本身不保证非线性收支合格。这里是特定 inner=1e-10 配置；不替换上一报告其他内层容差配置的数值。

## 4. 对下一步的决策

先评估固定宏步内的等长 Rodas 预测子步，复用同一移位矩阵 LU，形成分段慢驱动，再执行连续快修正。首先检验冻结模型，再检查原非线性系统及完整 Rodas 同等优化对照。该方案尚未由本诊断验证；内部非线性状态使用陈旧 Jacobian 不能自动继承原精确 Jacobian Rosenbrock 阶数。

优先采用可证伪的成本筛查：若改进刚性精度后多速率仍慢于同等完整方案或最快合格成熟求解器，就不进入正式重复。若局部正确性与成本均支持，下一关才是自生成完整短窗、累计误差／物理账本、估计／控制／独立审计总成本，最终再回到原正式 M4 矩阵。不给局部通过、冻结模型或单次计时赋予准入资格。
