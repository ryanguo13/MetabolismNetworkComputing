# M3 历史慢驱动的一次快流：修复短路径收支，仍缺效率

日期：2026-11-08（Asia/Shanghai），接续 [阶段共享与强对照挑战](m3-stage-sharing.md)。原 M4 两模型、两档精度、完整登记窗口、至少 50% 分裂覆盖、7 次正式重复、相对最快合格基线至少 1.5 倍中位加速的门槛不变。

**本轮取得了正确性进展：利用自己生成的三／四点慢 RHS 历史，只做一次快积分，小模型非恒定慢组首次在 H=.001 的 16 步诊断短路径上通过局部及累计物理收支。两个大模型短路径的三／四点版本也通过开发严格档。** 但连续积分整个短窗的完整对照明显更快，M4／PE 仍不准入。

## 1. 先分解账本误差

对原 MRI2／MRI3，在两个已有状态（t=.001、t=1）、常量／非恒定慢分组、九个减半步长 H=.008…3.125×10^-5、两个内层容差 10^-10／10^-12 上共做 144 次一步诊断。分组固定以隔离方法误差，不是在线分组策略。独立完整参考为 10^-12／10^-13；原误差与收支目标未改。

设输出为 P，参考解为 R，数值终点为 Y，账本权重为 w。使用相同 16 点 Gauss 积分，逐项重算恒等式：

`账本残差 = w·(Y−R(H)) + 参考账本残差 − ∫w·(F(P)−F(R))dt`。

各项使用原账本分母归一化。另用准确参考终点构造 Hermite，仅作为隔离输出误差的诊断，**没有把它当候选输出或免费历史**。

晚期非恒定慢组、H=.001、MRI3 的加权端点误差约 **1.760×10^-9**，输出积分偏差约 **−3.804×10^-8**，账本残差约 **3.980×10^-8**；参考端点 Hermite 的残差约 **3.13×10^-16**。这否定了“只要端点加权误差小，输出账本就足够准确”的推断。当前结果说明近似端点与刚性输出重建共同作用，不能把全部失败归因于 Hermite 的纯插值阶数。

将 H 减至 .000125 后，晚期两种方法的原账本均能通过；早期 MRI3 需减至 .0000625。误差阶只在超过内层容差差异／参考差异／舍入估计的点上报告；粗步到细步不呈统一渐近阶，不能用弱刚性理论阶替代实测。

早期三个最大步长的参考状态收紧预算通过，但单区间 8/16 点账本积分尚不一致，登记为参考积分未认证，相关候选不得通过该诊断资格。未用参考状态精度掩盖积分预算问题，也未据这些点作可靠的阶结论。

## 2. 文献启发与候选公式

实际检索 arXiv、Crossref，并阅读 Günther–Sandu 综述 **v1 的 §3、§6.1–6.3**。历史外推、多步初始化及其稳定性风险有成熟研究背景；Gear–Wells 1984 论文仅核对了 Crossref 元数据。本轮不是完整系统综述。

采用一个独立研究原型：在当前时刻和 q−1 个已计算时刻的慢 RHS `g(y)` 上构造 q−1 次多项式 P，随后只积分一次

`v′(t) = f_fast(v(t)) + P(t/H),  0 ≤ t ≤ H`。

q∈{2,3,4}。没有快项时，其端点退化为相应 Adams–Bashforth 积分；有快项时，用 Radau 求解当前修改快方程。非快活跃坐标按 P 的精确多项式积分演化。输出直接由这一个快方程的稠密多项式及非活跃坐标积分组成，**不存在 MRI 阶段拼接时间解释问题**。

这是一种受历史外推思想启发的加性分裂原型，并未宣称复现综述某个分量分区 MR-LMM 表或发明了新的方法族。综述中的分量分区定理不能直接证明本原型在强刚性加性分裂下的统一误差界。历史数据、步长比变化、启动和分组切换仍需验证。

自检用实际完整求解启动，验证弱刚性二至四阶收敛、线性守恒、非均匀历史、非活跃坐标精确积分、输出保存／恢复及两套账本。连续正性使用浮点多项式下界和驻点核验，仍不是区间算术证明。每个内部 RHS／接受状态、池、修改流与原物理账本均保留检查，未截断负值或投影修正终点。

## 3. 真实历史的局部筛查

预登记六个既有状态，q=2/3/4，容差 10^-6／10^-8／10^-10，自动或全区间起步；对应完整系统也获得三档容差与两种起步。共 144 条单次开发记录，包含 108 个候选、36 个对照。过去慢 RHS 从真实 MRI3 端点计算并缓存，当前慢 RHS 在候选计时内计算；独立参考未用于构造候选历史。

小模型非恒定慢组 H=.001 的三点候选，原物理账本约 **7.10×10^-11**，开发严格档实际误差最大约 **0.128 个目标单位**，均合格；二点版本账本约 2.37×10^-10，仍不合格。大模型原三阶段工作量进一步降至一个快流、通常 8 次 RHS／1 Jacobian／2 LU。

这些结果仍使用旧方法提供的历史，且只运行一次，没有预热或正式重复，不能用最快单次时间宣布 1.5 倍提速。于是追加如下自生成历史检验。

## 4. 自生成历史与整个短窗的完整对照

在看到局部结果后另行登记小模型 H=.001、大模型 H=.003／.001 三条固定分组路径，各 q=2/3/4、总共 16 步。首 q−1 步由实际有保护的完整 Radau 启动，之后只用本方法自己计算的端点／慢 RHS；启动成本计入候选。共九条路径、144 个宏步，全部走完。

每一步以及整个短路径都有独立 10^-12／10^-11 完整参考，65 点／宏步加原观测时刻，参考收紧预算均通过。即使误差超标仍沿正的数值状态做强制诊断，**失败步不是接受步、不是有效分裂覆盖**。负输出或积分失败才停止诊断。

## 5. 下一步评估

一次快流原型值得保留：它实际减少了快子积分，并修复小模型非恒定慢组的连续输出／账本。这是此前多个 MRI3 输出变体没有实现的组合。

但不应直接启动正式重复或 PE。当前短窗内完整系统能自动增长步长，固定宏步候选频繁启动，这是新的主要差距；多步累计误差又说明简单扩大 H 不安全。**下一优先级是验证有步长比限制的宏步增长和累计误差预算，并把启动、历史失效／分组切换、估计和独立审计的真实成本计入。** 先用开发轨迹检验可用步长是否足以缩小与连续完整对照的差距；若没有，就停止该配置的性能扩展。

没有证明全部 M4 条件，也没有降低账本、净通量、正性、池或审计标准。所有阶段选择、负结果、旧历史来源和后续补查的适应性均已记录。
