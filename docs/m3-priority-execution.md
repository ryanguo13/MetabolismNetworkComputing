# M3 优先级执行：P0 局部验证完成，P1 成本门槛未通过

日期：2026-11-07（Asia/Shanghai）。接续 [M3 瓶颈研究](m3-research-resolution.md) 的 P0→P3 路线，在 `test` 分支执行。

**结论：MRI2 + 完整 RHS Hermite 的局部正确性扩展取得进展，但本轮 P1 未观察到成本优势。按已登记停止条件，P2 在线控制器和 P3 正式完整窗口资格实验不启动，M4／PE 仍不准入。** 这不表示所有 MRI-GARK 方法无效，只适用于本次二阶格式、分组、误差控制与内核。

## 1. 本次实际实现

- 新增独立研究内核，保持历史 `metabolism/`、`tests/`、`checks/` 和旧证据不变。MRI2 公式沿用前轮 Sandu 式 (2.8)，没有 PE 或模型近似降阶。
- 快反应不更新的坐标按常 forcing 精确演化 `y_I(τ)=y_I(0)+q_Iτ`；快 RHS 始终读取这些变化后的值。大模型隐式子问题可从 3003 个坐标缩到 1946 个，但实测缩维不必然更快。
- 原生 CVODE/KLU 研究绑定复用分配与固定 CSC 结构，每个 forcing 变更调用 `CVodeReInit`，重置 BDF 历史；使用 one-step 模式检查所有接受内部状态，并设置 stop time，避免积分越过 forcing 区间。
- 比较单步隐式 Radau 与原生 BDF 子流；记录 RHS／Jacobian、接受步、线性 setup、分配和重初始化成本。`nlu` 与 KLU setup 保持不同语义。
- 对每个 Hermite 分量求导数的实根，检查端点和所有区间内驻点的最小值；负值曲线拒绝，不裁剪。这是 float64 多项式检查，不是区间算术正性证明，亦不是连续误差界。
- Teusink 新增两套独立收支：修改后快流 `wᵀ(f+q)` 沿内部数值轨迹做 4/8 点 Gauss 积分；原始物理 RHS `wᵀ(f+g)` 沿最终 Hermite 曲线做 8/16 点 Gauss 积分。两者各自检查积分差及残差，归一化阈值 `10^-10`。仅把状态变化记作账本会成为恒等式，故不采用。

“通过”同时要求实际浓度／通量误差、池、内部状态、Hermite 整区间非负及适用的两套收支检查；不是仅指积分器返回成功。

重要正反例：

- Teusink 在 `t=0,H=10^-6` 时，通量误差约 1.93 个宽档单位，收紧子流容差仍失败；降到 `H=10^-7` 后，严格档最大误差约 0.0284，收支同时通过。`t=10^-6` 的严格档也通过独立缩步补查。
- Teusink 初始层 `H=0.01` 的 4 个样例出现 Hermite 内部负值，全部拒绝。较大步长即使内部子流能完成，也不被计作正确输出。
- 大模型在 `t=0`、`10^-8` 的 `H=10^-8` 通过两档局部检查；早期 `H=10^-5`、`0.001` 仍超标。
- 大模型在 `t=0.1,H=0.01` 通过宽档，但不通过严档；`H=0.1` 的净通量局部误差约 217，`H=0.9` 达约 5.36×10^4。增大步长不是当前实现的免费加速手段。
- 修改后子流的守恒式账本残差最大约 `5.98×10^-12`，但较大步长原始物理收支可严重失败。因此“修改后子流账本闭合”不能代替原模型收支正确性。

补查完成后，两个模型的每个登记起点都至少有一个通过严档局部检查的配置。这里只建立局部可行性，不授权无审计在线接受。

第一批意外重复构建 `GroupScreen`，且完整系统对照缺少部分诊断包装，故仅保留为开发记录，**下面决策只用修正后的数据**。修正版缓存分组结构，把分类求值、粗步加两个细步、输出、独立完整 ODE 审计、误差后处理、适用收支全部计入。各内核构建成本单列，未加入稳态重用的单次计时；这给 MRI 有利的局部成本条件，完整窗口仍应计入构建。

### 成本判断

1. **分配不是主导解释。** 例如大模型 `H=0.001` 的一次缩维原生试算，六次分配累计约 0.0039 秒，内核总耗时约 0.456 秒；复用分配收益有限。
2. **重启后 KLU 符号分析仍发生。** 本机锁定的 SUNDIALS 6.4.1 源码 `src/sunlinsol/klu/sunlinsol_klu.c` 中 `SUNLinSolInitialize_KLU` 将 `first_factorize=1`，后续 setup 重做 `klu_analyze`。因此没有把“固定结构／内存复用”写成“复用了符号分解”。本轮未改动底层 SUNDIALS 或越过其私有 ABI。
3. **六次子积分启动仍有工作量。** 二阶粗细计算需 6 次快流；`H=0.001` 的一个 Radau 样例用了 6 个 Jacobian 和 12 次 LU。单步隐式法略快，仍未抵消整体成本。
4. **缩维不等于少分解成本。** 全坐标和缩维会改变误差权重、步长历史、稀疏排序及数值工作量，本轮缩维 BDF 反而更慢。未单独测量符号分析／数值 LU 的时间，不能把全部剩余耗时归因于某一项。

## 4. 本轮停在何处

| 优先级 | 结果 |
|---|---|
| P0 | 完成本轮登记的两模型、多起点、两容差、输出正性和开放收支局部验证；负结果全部保留 |
| P1 | 完成缓存纠正、缩维、内存重用、BDF/Radau 和更大 H 补查；没有测得优于完整系统的成本前景，触发停止条件 |
| P2 | 未启动新的在线误差控制器；已保存输出粗细差作为离线诊断，不能据本样本无漏检就宣称可靠 |
| P3 | 未开展正式全窗口 7 次重复；避免把无效率前景的试算包装成资格结果 |
| M4／PE | 保持不准入 |

进一步继续前，应提出**能消除实际工作量**且可独立验证的变化，例如成熟 MRI 嵌入对替代一次粗步、支持安全重用符号分析的原生线性求解路径、或低成本单步隐式核。它们都不是本轮已经实现或证实有效的改进；还需同时解决通量／输出估计的可靠性。不能直接沿用旧 BDF 历史、旧数值 LU、减少审计或放宽原目标来制造收益。
