# M3：原运行时审计输出职责与成本

日期：2026-11-15（Asia/Shanghai）。承接[原正式精度重评分](m3-formal-audit-reanalysis.md)。**保留原审计点后，减少冗余查询确实降低评分成本；大模型两状态、两正式档仍无正的1.5倍预算，M4不准入。** 本轮收束于局部成本假设，没有实现新的在线接受策略或 PE。

## 原职责与前瞻登记

核对 `metabolism/continuation.py` 的 MacroSplit：每个候选都从相同初始状态独立求解原完整非线性 ODE，在**所有区间公共输出点、四分之一、二分之一、四分之三和终点**核验候选。此前局部研究使用额外65点增强网格；固定65点不是原运行时职责。CVODE 包装对每个请求时刻调用一次 native output，因此需区分真实必需输出与研究加密输出。

本轮在新求解前冻结四个旧状态、H=.01、两种查询集合、每状态／正式档前轮事后选出的单审计内部容差及其十倍收紧。增强集合仍为65均匀点加公共输出；必需集合包含全部原公共输出和四分点，初值仅用于求解初始化，不计入运行时比较点。实际点数如下，未删除公共输出或原审计点。

| 状态 | 必需比较点 | 增强比较点 |
|---|---:|---:|
| Teusink，t=1 | 4 | 64 |
| Teusink，t=.001 | 32 | 92 |
| k-ecoli457，t=.1 | 4 | 64 |
| k-ecoli457，t=.001 | 15 | 75 |

原65／公共网格的独立 CVODE 真值仅用于离线资格评分，不参与候选生成、误差估计或运行时接受决定。最小查询结果只核验实际必需坐标，未取得65点连续曲线资格。每个配置预热一次、三次开发测量，方法轮换；合计128次审计尝试、480次成熟对照尝试，全部保留。

审计原非线性 RHS 新增与原 MacroSplit 相同的域检查：非有限或小于 `-1e-12*case.scale` 的内部状态拒绝，不裁剪。审计本身仍不具备完整连续曲线／物理账本认证，其耗时只作乐观成本筛查。成熟 OrderedRadau 自动／整步起步保留原连续正性、池、拼接和物理账本保护；大模型另外测相同查询集合下的 CVODE 完整成熟路径，保留内部 RHS 域／输出池检查，并明确 native accepted internal states 不暴露。Teusink 原 native full-only 明确不支持 quadrature ledger，因此不能省略其开放账本加入成熟 CVODE。

## 真实评分成本与预算边界

每次审计后计时执行一条固定的、此前实际生成并保存的 MERB1e-8 候选曲线评价与原 `observable_error` 运算。该候选不取自参考真值，不更换失败候选；评分检查浓度、单向通量及适用净通量，局部尺度保持 `.1*正式target` 和 `.1*net_target`。候选可能不合格，其实际分数与决定均保留；此处只测该形状运算的真实耗时。

候选生成成本没有在本轮重新计时，也没有被认定为零。下表余额扣除了审计求解、输出保护及真实候选比较，但尚未扣候选生成、分组、估计、控制器、启动、拒步和回滚。这是留给这些工作的乐观余额，不是候选端到端速度。

**参考资格仍为 `.05*正式target`，而运行时局部接受目标是 `.1*正式target`。** 前者可占后者的0.5个接受单位，因此本轮不能认证“不会误接受”。未来若要将选出的内部容差用于在线决定，必须按局部参考预算或实际接受裕量另做前瞻可靠性校准；不能把本成本研究的预算通过视为在线正确性通过。

## 小模型 current 后端实现错误与修正

第一批新脚本错误地把 `current` 一律派发到解析 Jacobian 的 CVODE；实际 Teusink 的 `flux_jacobian=None`，历史 `full/current` 会回退至未提供 Jacobian 的默认 SciPy Radau。因此早期 Teusink 的32条审计均以 NoneType Jacobian 实现错误失败。原源码、登记、失败和曲线保持不变，**这32条排除科学比较**，不记成方法失败或有效覆盖。

另行前瞻登记独立修正批，仅重跑该状态32条审计和96条匹配成熟对照。修正只恢复原 current 默认 SciPy Radau 分支，保留相同内部域保护、四个审计配置、两查询集合、候选、容差和全部成熟对照。32条审计全部完成，96条对照中48条内部 RHS 负值失败并保留；原第一批48条相同保护失败也保留。报告使用修正批早期小模型结果，其他状态使用原第一批结果，不从两批择快。

冻结的旧[审计预算报告](m3-audit-budget.md)曾称两模型 current 都是 CVODE，与实际源码分支不符；当前[容差校准报告](m3-audit-calibration.md)和正式重评分表已按实际后端更正，历史数据／时间未改写。

以下均为三次开发测量中位数，单位毫秒。成熟对照取本批同查询集合下最快合格配置。余额定义为 `成熟对照/1.5 − 审计与评分`。

减少额外查询的收益真实存在。晚期大模型宽档审计与评分从增强集合的31.166ms降至必需集合12.909ms，约降低2.41倍；同查询成熟对照也从13.113ms降至11.933ms，因此仍没有正余额。严格档对应38.885→22.776ms，也未跨线。即使将候选生成假设为免费，大模型四项仍失败。

小模型的正数只相对本批成熟 OrderedRadau 集合。早期 current 审计使用默认无 Jacobian Radau，尚缺同默认 Radau 的完整连续／开放账本成熟包装；不能把包装保护差异称为数值方法加速。鉴于大模型和同轮[选择反应内核](m3-selected-reactions.md)均无晋级信号，本轮不继续为局部正余额无限追加计时，更不组合成虚构的全窗口资格。
