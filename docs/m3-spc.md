# M3 SPC-MRI-GARK：一次快流修正与完整预测器成本

日期：2026-11-08（Asia/Shanghai）。接续[隐式慢历史报告](m3-implicit-history.md)。本轮复现已发表的二／三阶 SPC-MRI-GARK 主方法，并完成两个模型的局部检验。**一次快流消除了上一轮反复快积分的主要开销，但没有达到 M4 门槛。** 原两个模型、两档精度、完整登记窗口、至少 50% 分裂覆盖、7 次正式重复、相对最快合格成熟基线至少 1.5 倍中位加速的条件不变。

## 公式、实现与验证

依据 Roberts、Sarshar、Sandu，[Coupled Multirate Infinitesimal GARK Schemes for Stiff Systems with Multiple Time Scales](https://arxiv.org/abs/1812.00808v5)，定义 2.1／式 2.2 与附录 A.1.1、A.1.3。读取版本为 v5；发表 DOI：[10.1137/19M1266952](https://doi.org/10.1137/19M1266952)。附录印刷页 29（PDF 第 30 页）的系数经过文字提取和页面图像交叉核对。[来源记录](../results/m3-spc/literature-provenance.json)保留版本、章节、PDF 与页面渲染指纹。

实现 SDIRK2(1)2 和 SDIRK3(2)4 的主系数行，未实现嵌入估计器。每个宏步先对完整向量场 `f=F+S` 求解 SDIRK 阶段，再进行一次修正：

```text
Y_i = y_n + H sum_j a_ij f(Y_j)
v'(theta) = F(v(theta)) + sum_j gamma_j(theta/H) S(Y_j)
v(0) = y_n,  y_(n+1) = v(H)
```

完整预测器的所有 RHS、Jacobian、LU 和 Newton 更新计入成本。相同对角系数的阶段共享冻结 Jacobian／LU，必要时刷新；快求解器借用预测器反应梯度构造陈旧初始 Jacobian，保留正常刷新路径。慢阶段值从已经计算的完整通量中取出，避免重复评价。非活跃坐标精确积分仿射驱动；负状态不裁剪。曲线候选为原始快流输出或完整 RHS Hermite 输出，两者都核验原始快流正性与修改流账本，再对实际返回曲线检查原物理收支和误差。

三项自检验证：主系数积分与基方法阶条件、精确耦合线性系统与全快／全慢极限、非线性系统全局阶数。非线性三阶方法的粗步存在误差抵消，N=8/16/32/64 的观察阶约为 1.61/2.59/2.83/2.92；全部结果保留，测试采用渐近区间。二阶方法最终约 2.00。独立线性诊断显示，原始快流曲线的局部内部误差约二／三阶，Hermite 约三／四阶；这不构成真实强刚性模型连续输出的自动资格。

## 初始两模型筛查

首批登记 192 条记录：144 个 SPC 候选、12 个相同 SDIRK 基方法对照、36 个成熟完整 Radau 对照。Teusink 从 t=1 开始，阈值 `.3/3/10`；k-ecoli457 从 t=.1 开始，阈值 `.01/.1/1`。两者都测试 H=`.001/.003/.01`、二／三阶、两种输出和内层容差 `1e-6/1e-8`。预测器缩放残差上限初定 `1e-11`。

所有预测阶段和快修正都计时，分组、独立参考和误差评分在计时外；这是单次、乐观、局部开发比较。完整 Radau 同样使用三档容差和自动／全区间初始步。额外完整 SDIRK 对照采用与候选完全相同的预测器及 Hermite 输出，因此可检查快修正是否值得。实际浓度／单向通量开发目标为 `1e-4/1e-6`，大模型净通量目标仍为 `1e-4`，池与两套收支门槛仍为 `1e-10`；独立 `1e-12/1e-11` 参考须通过 `.05` 预算。这些开发短窗不替代 M4 原全窗口与原精度档。

小模型 72 个 SPC 尝试均完成；严格档最快比值为 .577/.611/.510（完整 Radau 时间／候选时间）。大模型 60 个 SPC 与 5 个 SDIRK 对照在预测阶段未收敛。诊断追踪发现，残差先快速下降，随后主要在 `1e-10–1e-9` 附近振荡，刷新 Jacobian 也未消除停滞。该现象与残差数值噪声一致，但本轮没有证明其全部来源；不能将所有失败解释成该方法数学上不稳定。

## 内部求解容差补测

独立追加登记 174 条大模型记录：预测器残差容差 `1e-9/1e-8` 下的 144 个 SPC、12 个同容差完整 SDIRK，以及 18 个 Radau 对照。方法系数、保护、实际误差与完整审计门槛不变；首批原结果完整保留。补测全部完成，其中 SPC 宽松档合格 90 个、严格档合格 60 个。

| H／精度 | 最快 SPC 毫秒 | 对最快合格 Radau 比值 | 对包含完整 SDIRK 的最快控制比值 |
|---|---:|---:|---:|
| .001／宽松 | 10.35 | 1.134 | .655 |
| .001／严格 | 11.48 | 1.023 | .590 |
| .003／宽松 | 10.90 | 1.123 | .702 |

| .01／宽松 | 15.17 | .900 | .627 |
| .01／严格 | 16.83 | .812 | .812 |

这些是单次开发比值，不是正式加速。新写的完整 SDIRK 控制不冒充已完成成熟基线认证；它的作用是给予候选预测器同等优化机会，检验额外快修正的必要性。即使只与本批最快合格成熟 Radau 比较，最高也只有约 1.13，仍未达到 1.5。

补测严格档 H=.001/.003 的最快候选都包含 13 次完整预测 RHS、1 个完整 Jacobian／LU，另加 8 次快 RHS 和 2 次快 LU；快 Jacobian 实际新评价为零，因为有效借用了预测器梯度。完整预测器约占候选时间的 55%。H=.01 则需要 19 次完整预测 RHS，额外快流没有抵消其成本。

小模型的瓶颈更直接：对本轮最快严格合格配置，单独预测器耗时约 1.139/1.247/1.939 毫秒，完整 Radau 对照约 1.645/1.811/2.211 毫秒。假设其他所有候选开销都为零、预测器工作量不变，时间比也只有 1.44/1.45/1.14。这个减项诊断只适用于已测配置，既不是实测加速，也不是所有 SPC 方法的普遍上界。

## 结论与下一优先级

SPC 主方法已通过公式与阶数核验，实际模型局部正确性有可用配置；内部求解容差造成的部分失败已通过独立补测澄清。但当前两／四个完整隐式预测阶段加一次快流的成本结构，没有展示跨过 M4 的前景，因此不进行正式全窗口重复或 PE 实施。

下一步优先检验**低成本线性隐式耦合／预测器**：先从已发表 GARK-ROS/ROW 条件或明确的展开推导出可核验公式，验证刚性耦合、阶数与输出，再比较总工作量。不能只删除 Newton 收敛条件后继续声称是原 SPC 方法。快 RHS 仍计算全部反应后切片，严格等价的子集计算可作辅线，但上述小模型减项诊断说明，单独优化快修正不足以挽救已测配置。完整基线继续获得同等优化机会。

独立 verifier 重算阶数诊断、残差轨迹和参考预算，重求每种预测器配置，核对所有保存的阶段方程、原通量、驱动系数、原始／最终曲线、两套账本、局部资格与最快合格比较。两批共 366 条记录及失败均保留，旧证据清单未变。M4 的两模型完整窗口、分裂覆盖及正式重复要求仍未完成。
