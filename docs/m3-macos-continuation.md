# M3 macOS 续作与 M4 再准入核验

日期：2026-11-07（Asia/Shanghai）；分支：`test`。

**M4 准入：`not_admitted`。** 16 个开发探针中 15 个完成完整窗口，1 个失败／超时，全部保留。积分成功仍需与分裂覆盖及效率区分。

本轮落实用户继续 M3 的要求，重新检验旧实现的输出落步、8 次尝试上限及分区重建限制；没有改写历史 M1–M3 结果，也没有实施 PE、M5 或 M6。

## macOS 环境

Python 3.12 与 `uv.lock` 锁定依赖；CPU float64、BLAS／OpenMP 单线程。Homebrew 的 SUNDIALS 7 与原 ctypes 绑定不兼容，因此从 SHA-256 固定的 6.4.1 源码构建项目专属 double/int64 CVODE-KLU，链接 Homebrew SuiteSparse。`metabolism` 在 macOS 自动发现本项目运行时，不改变 Linux／Windows 的路径。

本机默认 SDK 27 与 Apple 链接器不匹配；安装脚本使用已安装的 SDK 26.5，允许 `SDKROOT` 显式覆盖。运行时位于被忽略的 `.runtime/`，构建缓存位于 `results/scratch/`。

## 算法续作

- 宏步只受控制器和终点约束；公共 M1 观察网格、初值、物种／通量尺度及参考解均保持原样。
- 接受两个细步，不外推；输出采用细步节点间凸线性插值，保持非负性及线性守恒池。所有请求输出、1/4、1/2、3/4 和终点都由同一起点的独立完整 ODE 审计；审计状态不用于冒充分裂输出。
- 分组不变时复用分区矩阵；每步对缓存范数应用当前步长，避免步长增长时仍沿用旧快慢判定。频率 1／5 对比、初始层完整 ODE 前缀和进入阈值 1→0.01 的开发探针分别保留。
- 尝试预算由 8 提升至 512；连续拒步上限 16、每条轨迹 60 秒。初始层前缀从原始初值实际积分，不取保存参考状态作初值；剩余回退区间明确登记。
- 强刚性估计失准仍记录。因每个候选保留实际误差审计，控制器可依据实际误差继续缩步；这不构成廉价估计器，也不允许稀疏审计或未经审计的接受。

## 同机强基线

完整系统使用同一 RHS、输出网格、守恒／负值／开放收支诊断包装。Teusink 比较 BDF／Radau；k-ecoli457 再加入同 RHS、解析稀疏 Jacobian 的 CVODE-KLU。每种方法扫描 `rtol=10^-4,10^-6,10^-8,10^-10,10^-11`，按实际浓度、单向通量、大模型净通量及守恒／收支筛选配置，再独立预热并交错重复 7 次。

## 决策与边界

输出解耦、更多尝试、缓存及初始层前缀没有提供支持 M4 的效率证据。这些探针中，大模型没有接受分裂步；缩步后仍有净通量审计超标。小模型的完整窗口成功主要来自回退；扩大快组的一个探针在预算内未完成。因此本轮结果不能用于宣称纯分裂完整窗口资格、动态分组加速或 M4 准入。

`candidates.json` 按“精度达标、分裂覆盖至少半窗口、单次耗时优于达标基线”的规则筛选值得正式重复的配置；不存在候选时明确记录原因。只有进一步完成重复验证、满足原规划两模型／两精度档 1.5 倍有用性目标并通过正确性检查，才自动建议准入；当前证据连较弱的效率前景条件也未满足。不得通过取消审计、放宽净通量目标或把回退标成分裂来取得准入。

凸线性插值的资格仅覆盖请求网格与登记审计点，不是任意连续时刻误差定理；本轮未重新验证新控制器的事件／留出扰动／长期行为。原生 CVODE 未暴露全部内部接受状态或独立 LU 次数；失败时尚未返回的原生内部计数不可补造。未采集隔离 worker 峰值 RSS。

实质剩余项是能在强刚性及净通量取消误差下可靠工作的廉价估计／连续输出策略，以及避免反复数值快流重启的办法。这属于算法研究；本次 macOS 适配本身已经完成。

## 复现

```bash
bash scripts/setup-macos.sh
uv run python -m metabolism.m3_continuation --case probes
uv run python -m metabolism.m3_continuation --case baselines
uv run python -m metabolism.m3_continuation --case sensitivities
uv run python -m metabolism.m3_continuation --case candidates
uv run python -m metabolism.m3_continuation --case tests
uv run python -m metabolism.m3_continuation --case report
uv run python -m metabolism.m3_continuation --case check
uv run python -m metabolism.m3_report --check
```

`check` 只读取保存轨迹并重算误差、登记条件和 SHA-256，不重跑积分。新增测试保存在 `checks/`，与历史测试源码指纹分开；其中显式运行 macOS 原生 CVODE 矩阵指数核验，补充旧测试按 Linux 平台筛选而跳过的一项。
