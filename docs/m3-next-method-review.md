# M3 后续方法与实现成本复核

日期：2026-11-15（Asia/Shanghai）。本次独立核对既有源码与已保存报告，没有新增文献检索。**完整系统预测器不能计为反应分裂覆盖；局部核验和实现优化都不能替代 M4 原准入矩阵。**

## 已反复出现的原因

1. `remainder_curve.py` 用完整 J 与完整线性 IVP 表达非线性余项，`controlled_rational.py` 压缩完整 J 的作用。二者目前是完整系统预测诊断；串接真实快流后，预测阶段和快流阶段会重复承担完整网络工作。提高预测精度并不自动减少端到端成本。
2. [冻结仿射归因](m3-affine-attribution.md) 已发现精确快流不能修复上游慢驱动误差；[预测器子步](m3-subcycled-predictor.md) 又显示陈旧 J 破坏非线性精度，刷新恢复精度却增加成本。继续只收紧快流容差、复用相似但不相等矩阵，不能补齐这些缺口。
3. 完整 ODE 审计、连续输出物理收支、累计误差分别是独立约束。局部浓度误差合格、更多修正或稳定谱，都不能推翻物理账本反例；完整审计的当前负成本预算也不会因快内核更快而消失。

本次没有发现足以推翻既有负结果的公式实现错误。发现一项尚值得直接量化的评价冗余：`MRI`、`ExtrapolatedFlow` 的快 RHS 先计算完整 `system.flux` 再选列，快 Jacobian 先计算完整梯度再选行／列。缩小快活跃坐标虽然减少线性系统，却没有同步减少反应速率及导数的计算工作。现有论文／报告中的“快系统维数减少”不能因此推断 RHS 成本也同比减少。

## 本轮可直接检验的假设

固定反应列集合 F，在全部真实状态坐标上计算 `v_F(y)` 与 `Dv_F(y)`；慢驱动使用反应补集 S 的 `S_S v_S(y)`。速率律、参数、依赖、化学计量、分组及方法系数不变。这是现有真正反应分裂路径的实现消融，不引入新的近似或高阶方法声明。

新实现分别位于 `research/selected_reactions.py` 和 `research/selected_extrapolated.py`。k-ecoli 按原质量作用式直接选择参数／反应物／指数，导数仍使用乘积法，保留零浓度行为；SBML 重用已准入适配器的受限 MathML 翻译，保留局部参数、赋值规则、调控和共享物种。输入列保持调用顺序，重复／越界／非整数索引拒绝，空集合有明确零维结果。所有状态仍是完整状态，不冻结调控坐标。

五项单元检查独立比较原完整速率／导数再切片，覆盖正状态、k-ecoli 初始零状态、实际 SBML modifier、全列公平特化、非法输入，以及旧／新分裂连续曲线和两套账本。慢补集直接求和与原 `full-fast` 的求和顺序不同，因此单独核验其浮点差异，不能宣称逐位数值路径恒等。已有源文件和 manifest 保持不动。

成本入口 `research/m3_selected_cost.py` 预登记三个已有真实历史路径，排除已知小模型常量慢组；旧／新候选、完整成熟对照都获得适用优化。完整对照另外使用同一选择器的全部反应列，不能只优化候选。保持原连续正性、池、物理／修改账本和独立完整 ODE 核验；一次预热与三次交错重复只作开发筛查。

```bash
bash scripts/run-macos.sh -m unittest research.test_selected_reactions
bash scripts/run-macos.sh -m research.m3_selected_cost run
bash scripts/run-macos.sh -m research.m3_selected_cost write
```

停止条件是两模型中任一方缺少合格且具有端到端预算的候选。尤其若 `最快合格完整对照/1.5 - 候选 - 必需审计` 仍非正，不增加控制器和正式重复。既有历史由方法自行生成，但本轮供应历史和分组，尚未承担完整启动／自生成后续控制成本；这些成本必须在晋级前补齐。局部计时不赋予覆盖或 M4 资格。

## 如果实现消融仍无前景

一个可证伪、但**本轮尚未实现或认证**的下一方法假设是：对慢反应保留当前精确切线，只对慢非线性余项作曲线近似，同时在同一 IVP 中保留原快非线性反应：

\[
z'=f_F(z)+f_S(y)+J_S(z-y)+p_S(t/H),\qquad z(0)=y,
\]

其中 `J_S=S_S Dv_S(y)`，`N_S(d)=f_S(y+d)-f_S(y)-J_S d`。先取 `p_S=0` 生成自己的预测曲线，再用其半步／末步的慢反应余项构造二／三次修正驱动。冻结仿射反应系统下 `N_S=0`，该构造应精确回到完整仿射方程，因此可先独立矩阵指数核验，直接挑战现有显式慢历史的线性刚性失败。光滑固定有限 J 下可以推导经典局部误差，但这不是强刚性一致阶保证。

代价也必须先明确：`J_S` 可能把隐式活跃坐标扩为全系统，同一完整矩阵分解成本可能消除任何收益；重复解整段 IVP 也可能立刻失败。先只在小型仿射／非线性守恒例上核验公式、正性、连续输出和阶数，再比较同等优化完整系统。只有少量慢评价确实替代昂贵完整阶段、且总预算为正，才值得投入真实模型。本构造是否符合现有覆盖定义须单独登记；没有实际完整反应分区和可核验工作减少时不能记作真实多速率收益。

当前合理顺序仍是审计预算校准 → 固定列评价成本消融 → 必要时再决定新耦合假设。不能承诺这些步骤必能达到 M4。
