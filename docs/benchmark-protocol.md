# 基准模型与评估协议

规划版本 v0.3，2026-11-02（Asia/Shanghai）。**M1 已通过验收，E3 已形成小模型与可执行大模型基线，其余实验仍为计划。** 实际配置、精度上限和 M2 范围见 [M1 验收报告](m1-completion-report.md)、`results/m1-completion`；原协议的同实际精度、强基线和全开销原则保持有效。

## 1. 候选模型与准入条件

| 层级 | 候选 | 作用 | 来源及目前核验程度 |
|---|---|---|---|
| B0a | 闭合线性可逆链 `A ⇌ B → C`，另设 `A ⇌ B ⇌ C` | 解析／矩阵指数参考、时间尺度分离、多个共享反应组 | 未来构造；参数扫描快慢比 `1,10²,10⁴,10⁶`，无量纲化后定义 |
| B0b | 显式酶机制 `E+S ⇌ ES → E+P` | 区分 QSSA 与 PE、检验酶池和底物总量守恒 | 未来构造；不能把其结论自动推广到已约化 MM 模型 |
| B0c | Robertson 反应系统及强耦合反例 | 初始边界层、零初始分量、近零物种、失败回退 | 未来引入标准参数；不可逆快反应不得强行 PE |
| B1 | Teusink2000_Glycolysis，`BIOMD0000000064` | 小型真实酶动力学、可逆步骤、浓度尺度差异 | [BioModels](https://www.ebi.ac.uk/biomodels/BIOMD0000000064)、[R10]；模型目录身份已核对，未下载／运行 SBML |
| B2 | Chassagnole2002_Carbon_Metabolism，`BIOMD0000000051` | E. coli 的 PTS、糖酵解和 PPP，适合瞬态／输入扰动 | [BioModels](https://www.ebi.ac.uk/biomodels/BIOMD0000000051)、[R11]；身份已核对，未下载／运行 SBML |
| B3a | k-ecoli457 论文所述前序 core model，93 metabolites / 138 reactions | 中等规模核心代谢候选 | [R12] 正文报告规模；独立模型包、参数和来源链待 M1 核验 |
| B3b | k-ecoli457，337 metabolites / 457 model reactions | 覆盖核心碳代谢与氨基酸等通路的规模验证 | [论文及补充材料入口](https://www.nature.com/articles/ncomms13806)，[R12]；MATLAB/MAT 分发，转换成本未知 |

B1 实际 SBML 为 26 species / 17 reactions，独立动态浓度为 **14**；3 个赋值物种、2 个常量物种和 7 个边界物种不积分。B2 为 **18** 动态浓度、48 反应、7 条显式时间赋值规则，无事件；公开 MathSBML 复现图已核对，完整系统基线保留规则，首版自治分裂不准入。B3b 原始 MAT 为 **3003** 个展开状态、5239 个单向反应，未展开网络仍为 337 metabolites / 457 reactions；已通过原始 RHS／Jacobian／Octave 轨迹与来源稳态通量核验。B3a 未取得，不阻塞已有 B3b 的 M2 准入。

首选 B1 与 B2 验证模型语义，B3a 或 B3b 至少一个通过准入后才开展中等规模性能主张。若 B3a 不可获得，核验 B3b；两者都不合格则重新选公开动力学模型，记录原因。不可拿缺少速率律的 FBA 网络直接替代动力学 ODE。

每个模型的准入清单：

1. 原始来源、版本／下载日期、文件 SHA-256、引用和使用条件明确；模型文件的实际可用性与论文可访问性分开记录。
2. 状态、参数、单位、物质量／浓度、体积、边界物种、assignment/rate/algebraic rules、事件、初值逐项可解释。代数规则不能被静默丢弃。
3. 用原模型执行器复现至少一个公开轨迹或稳态；若论文主要验证稳态，则明确瞬态仅作数值算法 benchmark，不冒称已获生物学瞬态验证。
4. 新 RHS 与原执行器在同样输入和参数下吻合；只检查残差或守恒不足以确认模型翻译正确。
5. 存在真实的多时间尺度与可讨论的快块，且速率律在目标域内合法。不因模型“是代谢网”就假定适合 PE。

## 2. 比较方法与参考解

| ID | 方法 | 比较目的 |
|---|---|---|
| REF | 完整系统高精度 Radau 与 BDF/CVODE 交叉检查 | 外部参考；不能把待测方法的更小步长作为唯一真值 |
| C1 | 完整系统 BDF，提供稀疏 Jacobian 或正确 sparsity | 实用强基线 |
| C2 | 完整系统 Radau，提供同等 Jacobian 信息 | 单步刚性基线与参考核验 |
| C3 | CVODE-BDF + 合适的稀疏直接法或 Krylov 配置 | 中等规模性能结论必需的成熟基线；配置应实际记录 |
| S0 | 固定分组 Lie-Trotter | 一阶对照与误差来源排查 |
| S1 | 固定分组 Strang + 外层自适应 | 隔离动态分组价值 |
| S2 | 动态分组 Strang + 相同子求解器，无 PE | 本项目第一阶段候选 |
| S3 | S2 + 局部精确反应流 | 区分解析子流收益与 PE 收益 |
| S4 | S2 + 有条件 PE + 独立偏差审计 | 第二阶段候选，可能因开销或偏差被淘汰 |
| C4 | 成熟 IMEX / MRI-GARK（如 ARKODE 相应方法） | M5 的补充比较；缺失时限制对多速率方法优越性的声明 |

显式 Euler 或 RK45 可用于展示刚性影响，不能作为加速主结论的唯一基线。基线与候选统一 float64、RHS 语义、Jacobian 可用性、线程数和硬件。候选若使用编译 RHS，基线也应可调用同等版本。

参考解的拟定流程：初始 `rtol=10^-10`、物种尺度化 `atol_i=10^-12 s_i`，再收紧至少一档；在公共输出网格上与另一算法比较。两参考解差异应小于最严格待测目标误差的 5%，且继续收紧无实质变化。若到达舍入／病态极限，放宽最严格评估目标或换高精度参考；不能直接称双精度结果为精确解。

M1 已据此冻结：小模型浓度／通量目标 `10^-3,10^-5,10^-7`；k-ecoli457 浓度／基元单向通量目标 `10^-3,10^-5`，按原 `get_Vnet.m` 恢复的总体净通量目标 `10^-2,10^-3`。更严格净通量因大正反向通量抵消而未通过参考预算；证据与停止的更紧 Radau 探针均保留。大模型采用相同 Python RHS、解析稀疏 Jacobian 的 SciPy 与原生 CVODE-KLU；不同平台计时不混合比较。

## 3. 精度与结构指标

### 3.1 轨迹与通量

每个物种预先给定正尺度 `s_i`，来自模型单位、物理量级或开发阶段参考轨迹；进入正式评估后固定，不按方法单独调节。使用

$$
w_i(t)=a_i+r\max(|x_i^{ref}(t)|,s_i),\qquad
E_\infty=\max_{i,t\in\mathcal T}\frac{|x_i(t)-x_i^{ref}(t)|}{w_i(t)}.
$$

初步目标档位 `r∈{10^-3,10^-5,10^-7}`，`a_i=10^-2 r s_i`；通过 M1 的参考解可靠性检查后锁定。`E∞≤1` 只是这一固定评估网格上的误差达标，不是连续时间误差证明。

外层控制器使用加权 RMS；最终验收同时报告最大分量误差，避免微量关键物种被 RMS 平均掩盖。输出网格包含初始层的对数密集点、全程均匀点、事件两侧和关键峰值区；先在开发参考解上固定，并做网格加密检查。插值的选择和开销对所有方法一致；终点误差不能代替轨迹误差。

通量以原始速率律在各方法轨迹上重算，使用单独的物理尺度与近零绝对误差下限；PE 若只提供浓度，不自动假定它能恢复正确的快反应净通量。报告关键通量积分、稳态值；若确有振荡，另报告周期与相位误差。

**同容差不等于同精度。** 扫描各求解器内部容差，绘制实际 `E∞`—耗时曲线，在共同精度档位比较最快达标配置；配置选择用开发集，冻结后评价留出扰动。

### 3.2 守恒和收支

闭系统对独立、规范化的不变量基 `L`，记录

$$
E_L=\max_t\frac{\|L^T(x(t)-x_0)\|_\infty}
{\max(\|L^Tx_0\|_\infty,\ell_{scale})}.
$$

先评估基底条件数和尺度，初步目标 `E_L≤10^-10`；若模型／基底病态，M1 应预先确定合理门槛。开放系统验证

$$
L^Tx(t)-L^Tx_0-\int_0^tL^Tb(x(s),u(s))\,ds
$$

及离散事件跳变，积分误差单独控制。只能对真正的闭合守恒池使用常量约束。

### 3.3 非负性、稳定性与近似偏差

- 记录所有步末和可访问内部阶段的最小原始浓度、负值次数、最负值；展示前不得裁剪。
- 可将 `-10^-12 s_i` 暂作显著负值报警线，M1 按尺度冻结；该门槛并非“严格非负”的证明。无法监测全部内部状态时明确记录限制。
- 报告 NaN、积分失败、最小步长耗尽、超时、回退及连续拒步。失败样本不得从性能统计中悄然剔除。
- S4 另报告 PE 阈值收紧曲线、PE 与无 PE 的轨迹差、约束重构范数、误差审计成本。局部 PE 残差小不等于全轨迹近似误差小。

## 4. 实验矩阵：先小后大

| 实验 | 配置 | 检查内容 | 顺序 |
|---|---|---|---|
| E1 基础正确性 | B0，各方法，固定分组，逐次减半步长 | Lie / Strang 渐近阶、解析参考、不变量、零初始值 | M2 |
| E2 刚度与耦合 | B0 快慢比扫描；近平衡与远平衡初值；共享物种 | 阶降低、估计器失效区、稳定性与反例 | M2–M3 |
| E3 模型基线 | B1/B2 和合格 B3，C1–C3 | 失败率、耗时分解、Jacobians、有效刚度诊断 | M1 后扩充 |
| E4 动态分组消融 | S1/S2，重估周期 1/5/20，滞回开／关 | 分组是否值得，切换是否引起抖动 | M3 |
| E5 PE 消融 | S2/S3/S4；三档 PE 资格阈值 | 分裂、解析流与降阶收益能否区分 | M4 |
| E6 长期稳定性 | 合格真实模型，原报告时间窗 `T` 与 `10T` | 稳态偏差、漂移、累积投影误差；必要时再加 `100T` | M5 |
| E7 参数／输入扰动 | 每模型固定种子的 20 组有效扰动；事件输入 | 时间尺度改变、重新分组、回退稳定性 | M5 |
| E8 观测噪声敏感性 | 如有对应观测任务，浓度观测加入 1%/5% 噪声 | 数值误差相对观测误差的量级；非积分稳定性主结论 | M5 可选 |

E7 优先在合法域内对速率参数做 ±10% 扰动；正参数可用对数采样。可逆反应须保持已知平衡常数／热力学一致性（如同时缩放一对正反向速率）；不要独立扰动而制造不物理的循环。初值扰动若要求守恒池固定，在相容类内生成并保持非负。事件输入需对全部方法使用相同语义和时刻。

时间窗、关键物种、扰动种子及参数约束在 M1 登记后冻结。不存在实验数据时，不把 E8 描述为生物学验证；不进行参数拟合，也不把观测噪声改成系统内在随机噪声。

## 5. 计时与成本归因

每配置预热后至少重复 7 次，交错运行以减小机器负载漂移；报告中位数、四分位距和全部重复值。低耗时样例批量重复到可稳定计时，重复数对各方法一致；不从毫秒级单次测量推断加速。

分别报告模型解析／编译等一次性 setup 时间、每轨迹积分时间，以及包含 setup 的单次任务端到端时间。积分计时必须包含分类、Jacobian 构建／分解、子求解器启动、粗细双算、PE 约束求解、投影、拒步、审计和回退；绘图与统一离线参考解生成不计入待测方法耗时。**若候选运行时需要影子参考步，该参考步必须计入候选耗时。**

记录 `nfev / njev / nlu`、接受／拒绝宏步、子步数、分组切换数、PE 覆盖率、回退比例、峰值内存、CPU 线程和软件版本。不同库统计口径可能不同，无法对齐时注明，不用“相同步数”替代“相同成本”。

$$
\mathrm{speedup}=T_{\text{最快达标成熟基线}}/T_{\text{候选}}.
$$

只在双方均达标时给出该比值；同时展示失败率。跨语言或编译层次的比较标记为“软件实现层比较”，通过同 RHS 条件的消融再讨论算法贡献。

## 6. 结果模板与决策

每次运行至少保存：`model_id, model_hash, case_id, seed, method, config, accuracy_target, observed_error, invariant_or_balance_error, min_raw_concentration, status, failure_reason, runtime_breakdown, solver_counts, software_versions, hardware`。M1 首轮已保存可取得的字段；未取得的内部统计和峰值内存显式记为 null，不填入推测数据。

主报告必须含：工作量—精度图、守恒／收支与最小浓度、长期轨迹、分组与 PE 历史、耗时分解、扰动失败率、所有消融和负结果。达到 [项目规划](project-plan.md) 的性能目标后，仍仅针对测试过的模型与参数域作结论。
