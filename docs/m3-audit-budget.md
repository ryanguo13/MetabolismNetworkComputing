# M3：同精度独立完整审计的成本预算

日期：2026-11-08。承接 [连续余项修正](m3-remainder-curve.md) 的第一优先级。**已验证优化能降低审计成本，但这批实现仍没有 M4 的正成本预算。** 未删除完整 ODE 审计、改变精度／结构门槛或开始 PE。

## 为什么先做这项

上一批两个模型在较晚状态 H=.01 已有开发严格合格的连续预测，但独立参考对成本高于成熟完整基线。直接继续叠加有理作用或快流，不能解决这项独立开销。另一方面，既有 [优化审计研究](m3-followup-evaluation.md) 已证明求解器实现会改变成本，不能从较慢 CVODE 包装直接推断一切完整审计不可行。

本轮在四个已知开发状态重测 H=.01：两模型较晚前缀索引 3 与较早索引 2。保持原非线性 ODE、相同初值、65 点／公共观察网格、1e-12 与 1e-11 收紧对，以及相对独立已保存 CVODE 参考的 .05 个开发严格误差单位预算。没有使用候选曲线或线性预测代替参考。

## 预登记与测量

三种完整审计：现有 `full` 包装、优化 OrderedRadau 自动起步、优化 OrderedRadau 整宏步起步。当前两模型的 `full` 路径均使用 CVODE。一次预热加三次开发重复，按重复轮换方法顺序，共 48 对完整审计。每个审计对的两条曲线均须通过与原独立参考的浓度／通量／净通量预算，收紧对之间也须通过相同预算。

成熟对照享有相同优化，容差 1e-6、1e-7、1e-8、1e-10，自动／整步起步，同样预热加三次重复，共 128 条记录；计时包含连续非负、池、适用物理账本和采样保护。参考求解、参考评分分别计时；用于否决成本前景的预算先只计参考求解，是对候选有利的乐观估计。模型准备和筛查对象初始化单列。

这不是正式七次重复。运行时此前实验数据正在后台 Git 上传，因此不能把本批计时精度或机器独占条件当作正式基准；后续若存在正的晋级迹象，必须在可控负载下重测。这里所有比较相差数倍以上，仍只作本批实现的局部开发筛选，不推导普遍复杂度下界。

48 个审计对全部通过预算。成熟对照有 16 条负内部 RHS 状态失败，均保留；不从这些失败配置计算合格基线。每个配置须三次计时重复都合格才参与中位数选择。所有保存参考的预算、成熟曲线的结构／账本／实际误差、同方法重复输出及工作计数的一致性已重检，160 个 NPZ 的 CRC 通过。

## 严格开发档结果

表中时间均为三次开发重复的中位秒数，最优审计仍是完整非线性 ODE 的两次求解。

| 状态 | 最快合格成熟对照 | 最快合格完整审计对 | 对照／审计 | 1.5 倍目标下给候选内核的剩余预算 |
|---|---:|---:|---:|---:|
| Teusink，t=1 | .002525 | .007308（当前 CVODE） | .3455 | −.005625 |
| Teusink，t=.001 | .033899 | .333754（优化 Radau 自动） | .1016 | −.311154 |
| k-ecoli457，t=.1 | .014241 | .150912（优化 Radau 自动） | .09436 | −.141419 |
| k-ecoli457，t=.001 | .152428 | 1.251992（优化 Radau 自动） | .1217 | −1.150374 |

剩余预算定义为 `最快合格成熟对照/1.5 − 最快合格审计对`。宽档结果也没有正预算。特别地，较晚大模型当前 CVODE 对为 .663949 秒，优化 Radau 对为 .150912 秒，约改善 4.40 倍；这项改善是真实测量结果，但完整审计对仍约为最快成熟对照的 10.60 倍。参考评分尚未计入该成本；加评分后最优审计流程约 .197455 秒。

这些数值否决的是**本轮相同高精度配对策略和实现**的晋级。不能直接证明单条审计、不同合格容差、合法跨步复用或整个窗口都不可能；也不能把统一离线真值生成与候选运行时影子审计混为一谈。若算法运行时依赖这个配对策略，其求解及评分成本必须计入，不能把它改标“离线”就宣称获得速度。

## 下一步取舍

1. 暂缓把有理线性动作和非线性修正拼成更复杂的反应分裂控制器，当前审计预算已独立否决这条直接组合。
2. 先研究是否存在**同一个 .05 误差预算下更低工作量的完整审计**：检查目前 1e-12／1e-11 是否过度求解，在独立真值上预登记内部求解容差与收紧策略的校准，保留原浓度、通量、净通量及结构门槛。内部容差不是可随意放宽的验收目标；任何变化都须由独立预算验证，失败与评分成本完整保留。
3. 同时明确运行时审计与离线资格真值各自必须承担的职责。只有能保持完整 ODE 核验、可靠收紧与正的端到端预算，才继续刚性余项表示及真正反应分裂；若不存在，就应如实报告现有约束下没有可晋级方案。不能用移除审计、弱化门槛或把完整预测计为分裂覆盖来通过 M4。

当前 M4 不准入；目标仍未完成。这项实验提供的是停止盲目优化内核的定量依据，不是正式性能结论。
