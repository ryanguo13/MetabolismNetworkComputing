# M3：慢反应切线与自生成余项修正的设计复核

日期：2026-11-15（Asia/Shanghai）。本轮依据本地公式、源码和准入记录作独立数学复核，没有新增文献检索。它是[后续方法复核](m3-next-method-review.md)中尚未验证假设的具体化，不声称实现了已发表 tableau 或获得新颖性证明。**本阶段是修改方程的机制诊断，不计 M4 分裂覆盖，也不授予正式精度或效率资格。**

## 方程与实际被近似的对象

固定完整反应组的真实分区 F／S，令化学计量矩阵为 C，反应速率为 v。这里 C 避免与慢反应集合 S 混名。在宏步起点 y 计算慢反应速率 vS0 与当前精确慢梯度 GS，定义

```
fF(z) = C_F v_F(z)
fS0   = C_S vS0
JS    = C_S GS
nS(d) = v_S(y+d) - vS0 - GS d
```

第零次预测和后续第 k 次修正分别求解

```
z_0' = fF(z_0) + fS0 + JS (z_0-y),       z_0(0)=y
z_k' = fF(z_k) + fS0 + JS (z_k-y) + p_k(t/H), z_k(0)=y
```

在上一条自生成曲线 z_(k-1) 的 H/2、H 评价慢反应余项 n_half、n_end，构造

```
a_k = 8 n_half - n_end
b_k = 2 n_end - 8 n_half
p_k(q) = C_S (a_k q² + b_k q³)
```

余项先在反应空间计算再乘化学计量矩阵；不要以完整 f 减两个大向量替代这条定义。原始曲线、速率、梯度、余项及驱动系数应保存，任何参考真值都不能参与曲线或驱动生成。

这里保留了快反应的真实非线性，但慢反应以切线加自生成余项表示。实际 Newton Jacobian 是 `J_F(z)+JS`，不是单独的快 Jacobian；JS 不应从快反应线性系统或成本统计中消失。所有修正都从同一 y 重解整个区间，上一条曲线只提供余项，不把其末点作为该次修正初值。

## 经典局部阶与不能推广的部分

对固定有限 Jacobian、足够光滑且处于动力学定义域内的问题，位移 d(t)=O(H)，慢余项 nS(d(t))=O(H²)，其对 d 的导数为 O(H)。忽略余项的第零次预测因而有 O(H³) 的整段单步误差。

一次修正使用第零次曲线，余项输入误差是 O(H)×O(H³)=O(H⁴)。真实慢余项随时间的展开从 t² 开始；由已知常数项和一次项为零、以及 H/2、H 两个值重建二／三次项，其整段插值误差同样为 O(H⁴)。在固定有限 Lipschitz 常数下对变分方程积分，得到一次修正的整段单步误差 O(H⁵)。配合稳定性与其他实现条件，才可能得到经典全局四阶。

第二次修正可减小输入曲线误差，但两点三次余项表示仍有 O(H⁴) 插值余量，**不会自动把方法提升为五阶或更高阶**。这些估计的常数可能随刚度增长，不是对任意 H‖J‖ 的刚性一致阶定理。内层 Radau 的误差、三次稠密输出、非正规放大、负值拒绝和浮点抵消还须独立验证；不能仅依据上述展开给真实模型曲线贴四阶标签。

## 必须成立的独立极限与结构检查

| 检查 | 可核验预期 | 能说明的边界 |
|---|---|---|
| 慢反应全部仿射，快反应可非线性 | nS=0，修改方程与原完整 ODE 相同，修正应不改变方程 | 不依赖整体系统仿射；可直接检出慢切线／余项实现错误 |
| 整体仿射系统 | 任意真实分区都回到同一个完整仿射 IVP，与独立增广矩阵指数比较整段曲线 | 检查公式与输出，不证明非线性或刚性一致阶 |
| 全快 | 完整原非线性 ODE，修正驱动为零 | 是完整求解器退化对照，分裂覆盖为零 |
| 全慢 | 退化为既有 `RemainderCurve` 的完整 Jacobian 余项迭代 | 是旧完整预测器极限，分裂覆盖为零 |
| 闭系统 LᵀC=0 | 所有精确修改向量场都保留 Lᵀz；数值阶段、连续曲线仍核验 | 代数守恒不推出正性、实际轨迹精度或开放收支 |
| 开放系统 | 修改方程账本与原完整物理账本分别计算 | 修改账本小不能代替物理账本小 |
| 非法初值／内部负状态／曲线负极值 | 明确拒绝并保留原因、计数和成本 | 不裁剪，不用参考修复候选 |

适用物理账本继续沿用原完整 RHS。修改账本积分本次实际的 `fF(z)+fS0+JS(z-y)+p(q)`，并检查累计缺陷与求积误差；分段求积差应累计绝对值，避免不同段相消后掩盖误差。没有配置的开放账本应标为不适用，不把缺字段解释为测得零值。

## 与既有研究的区别及覆盖边界

`remainder_curve.py` 对完整反应作切线化，再求完整线性 IVP；本构造只对慢反应作切线化，在每次内部评价保留快反应非线性。`ExtrapolatedFlow` 用过去慢 RHS 的外推驱动快流，本构造把当前慢切线保留在隐式方程中，预期挑战其线性刚性稳定性障碍。`ROWContinuous` 使用完整 ROW 阶段构造慢驱动；本构造不用这组完整预测阶段，但要承担多次区间 IVP。

它仍然是全维修改 ODE 的加法分区算法，不是原 F／S 精确子流的 Lie／Strang 串接。反应组真实、慢速率评价次数少，并不自动等于已证明的有效多速率求解。另一方面，隐式维数覆盖全系统本身也不构成所有 MRI 类方法失格的数学证明；关键是实际哪个方程、哪些反应在什么频率被求值，以及近似误差与真实成本是否完整核验。

当前实现尚无自生成全路径、在线误差控制、动态分组／回滚及正式性能证据，因此本轮所有记录的 `reaction_split_coverage` 和正式 M4 覆盖贡献都为零。未来若提出对混合非退化分区的覆盖资格，应另行登记控制器语义，核验确实减少慢反应评价、候选独立生成、逐候选完整 ODE 核验与正确接受区间，并明确与完整求解退化情形的区别。不能复用现有仅检查 groups 非空的标签直接授予资格。

## 工作量与公平停止条件

每个宏步至少需要一套当前慢速率／梯度、一个预测 IVP，以及每次修正的两次慢速率评价和另一个整个区间 IVP。若当前实现仍先计算完整速率再切片，快 RHS 调用也承担全部反应评价；在此实现下不能宣称实际慢速率调用减少。若用选定反应求值器，则成熟完整基线也获得同等表达式／梯度优化机会。

`J_F(z)+JS` 的支持可能扩展为全系统，且不同状态、步长或修正的移位矩阵通常不同。只有元素、索引和 dtype 完全一致才能称为精确 LU 复用；陈旧因子若只作预条件器，须独立核验当前线性残差并记入修正／重分解成本。不能因 JS 冻结而把整个 Jacobian 或 LU 都当作不变。

先做上述独立极限、自生成弱刚性阶数和刚性负例，再用实际两模型做小批局部筛查。所有实际初值、分区、步长、修正次数、内层容差、参考预算和候选停止条件必须在新数据前登记。成熟对照在同一区间不中断求解，并获得相同自动／整步起步、合理容差、RHS／Jacobian、连续保护和优化机会。两模型的原正式误差档与较严开发档分别报告，不能互相替代。

若任一模型中最快合格候选即使不含独立审计也超过 `最快合格成熟基线/1.5`，直接停止本实现晋级；不增加在线控制器或七次正式重复。若尚有乐观余量，还须扣除逐候选完整审计、实际比较评分、启动、分组、控制、拒步和累计保护，才决定是否值得自生成多步验证。局部后验选优和单次计时都不是正式性能证据。

原两模型、两正式精度档、原完整窗口、至少 50% 合格真实分裂覆盖、七次正式重复及中位端到端至少 1.5 倍的要求保持不变。这份设计复核只明确下一假设如何被支持或否定，不预先保证能跨过 M4。
