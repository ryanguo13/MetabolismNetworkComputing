# M4 新算法假设评审

日期：2026-11-16（Asia/Shanghai）  
范围：只评审已有证据下可证伪的算法假设；不实现原型、不运行完整窗口、不启动七次正式重复。

## 决策

**当前没有可进入下一算法原型的候选。**这不是“所有未来算法均不可能”的结论，而是冻结 M4 协议下的继续门未通过：没有候选同时说明了真实反应分裂、两模型可执行性、保留逐接受步独立完整非线性 ODE 审计后的正成本预算，以及达到全窗门槛的最小验证路径。故本批不启动新算法代码或 M4 正式试验；M4 维持 `not_admitted`，PE/M5/M6 不启动。

M4 硬门不变：Teusink 与 k-ecoli457；两档浓度/单向通量精度（大模型另核净通量）；完整登记窗口；至少 50% 的实际反应分裂覆盖；7 次独立正式重复；同机最快合格成熟基线下中位端到端加速至少 `1.5x`。候选生成、控制、分组、输出、物理账本、拒步/回滚及每个接受候选的独立完整 ODE 审计都计入端到端时间。

## 后续顺序与停止条件

1. **停止新增算法原型和完整窗口资源投入。**当前所有可运行路径在候选成本或端到端预算处已失败；仅靠缩小审计墙钟不能跨过剩余差额。
2. **只有出现可测的外部变化才重开算法筛选：**例如新的、与当前不同的稀疏线性代数/求解器运行时在同机配对基准中证明候选与完整审计总预算显著下降；或提出一个保留每个接受步完整独立 ODE 核验、且有可证明成本省项的真实反应分裂公式。外部变化本身不构成准入，仍须用相同精度和最强成熟基线复核。
3. 变化发生后先登记单一可证伪假设，明确公式、真实反应列覆盖、两模型可执行性、非负性/两套账本/连续输出检查，以及候选+控制+审计的实测成本上限。第一阶段仅做小系统正确性与真实状态局部成本筛查；任一模型/任一正式目标无正预算即停止。只有两模型均有预算后，才另行批准短窗和正式重复。

本批没有新运行、代码或结果产物；既有历史结果、指纹和 admission state 均保持原样。

## 2026-11-17：SUNDIALS 7.9 ExtSTS 外部变化筛查

- [x] 外部方法扫描发现 SUNDIALS v7.9.0（2026-09-03）在 ARKODE/MRIStep 增加 ExtSTS；相关论文为 Reynolds、Amihere、Aggul，“Implicit-explicit and split-explicit super-time-stepping methods”，arXiv:2608.02823。论文将 STS 用于扩散分量，并对其余分量采用显式、隐式或 IMEX RK；嵌入式误差估计可支持自适应控制。
- [x] 可迁移假设：将真实快反应列作为 STS 分量，其余真实反应列作为显式/隐式外层分量；如果估计器和嵌入控制能在反应动力学上正确工作，可能减少候选生成成本，同时仍对每个接受宏步执行完整独立非线性 ODE 审计。纯反应 ODE 没有扩散项，因此这是新映射，不能直接引用论文的 PDE 成本结论。
- [x] 本地项目当前锁定 SUNDIALS 6.4.1，现有 CVODE ctypes 绑定不能直接代表 7.9 的 ARKODE 行为。用临时 `uv run --with sundials4py==7.9.0` 环境确认新接口存在，没有更改项目依赖、ABI 或正式基线。
- [x] 最小标量 smoke test 尚未通过：对 `y'=-1000y-0.1y`、`h=0.01` 的试跑返回约 `0.825`，而精确值约 `4.5e-5`；首次构造还确认 ExtSTS 需要至少一个外层 `fE`/`fI` 分量。试跑没有完成可验证的自适应误差控制，故只记为未通过的接口探针，不归因为方法理论失败，也不作为任何精度或成本证据。
- [ ] 下一步继续门：先用正确的 SUNDIALS 7.9 ExtSTS 配置和嵌入控制通过已知衰减/守恒小系统的精度、内部非负性与拒步回滚测试；再测 k-ecoli457 与 Teusink 真实状态下候选加逐步完整审计的局部预算。任一模型或正式目标无正预算即停止；不进入完整窗口或七次正式重复。
- [x] 结论：该外部版本变化提供一个新的、可证伪的局部可行性检查，但当前尚无可用候选，M4 保持 `not_admitted`，PE/M5/M6 不启动。历史结果、登记和 admission state 均未改写。
