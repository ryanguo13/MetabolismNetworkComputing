# M3：原快非线性反应与慢切线余项耦合

日期：2026-11-15（Asia/Shanghai）。承接[后续方法复核](m3-next-method-review.md)最后一项假设。**慢切线耦合在较晚状态扩大了合格宏步，但当前实现仍慢于同精度完整系统；M4 不准入。** 本轮没有满足原两模型、两正式精度档、完整窗口、至少50%真实反应分裂覆盖、七次正式重复及中位端到端1.5倍的组合要求。

## 方程与真实工作量

固定完整反应组快集 F 与慢补集 S。在宏步起点 y 计算慢反应切线 `J_S=S_S Dv_S(y)`，求解

```
z′ = f_F(z) + f_S(y) + J_S(z-y) + q²(A+qB),  q=t/H, z(0)=y.
```

第一次取 A=B=0；随后在自己上一条曲线的半步与终点评价慢反应余项

```
n_S(z) = v_S(z) − v_S(y) − Dv_S(y)(z-y),
A = S_S(8n_half − n_end), B = S_S(2n_end − 8n_half).
```

分别测试零／一／两轮修正；每轮重新从同一真实 y 解整段修改 IVP，不把前一轮的终点当作新起点。原快反应保留非线性，当前修改方程 Jacobian 为 `Df_F(z)+J_S`，不把变化矩阵称为精确 LU 复用。所有真实反应依赖完整状态，未冻结调控物种，也没有参考轨迹驱动候选。

本实现直接调用通用完整速率／梯度再取快列，故每次快 RHS 仍包含完整网络速率评价；计数明确记录完整速率调用，不能声称真正减少了慢速率实际计算。`J_S` 可引入快活跃块以外的隐式耦合，因此本轮始终求完整向量：Teusink 14维，大模型3003维。真实反应分区不自动意味着有效多速率工作量减少，本轮 `reaction_split_coverage=0`，不凭这种局部修改方程给出 M4 覆盖资格。

内核保存每轮完整连续曲线和阶段／速率／余项／forcing。原状态定义域、内部状态、连续极值非负、拼接、池和最终原物理账本均检查；显著负值拒绝，不裁剪。修改方程账本独立积分实际 `f_F+f_S(y)+J_S(z-y)+p`，采用每段 Gauss8/16绝对差累加，避免不同段求积差抵消。原物理账本沿既有独立完整 RHS 求积口径，不能用修改方程收支替代它。预测曲线的原物理账本可不满足最终外部门槛，它是后续修正的输入；最终曲线必须通过原门槛。

## 独立自检与适用边界

六项单元检查通过：独立增广矩阵指数的冻结仿射精确性；DOP853逐轮重建修改 IVP、半步／终点阶段和 Vandermonde forcing；全快完整 ODE、全慢完整余项两种极限；守恒池与开放物理／修改账本；弱刚性连续单步误差；非法初值在速率评价前拒绝。

在已测光滑固定有限 Jacobian 小系统，H=.05到.025时，零／一／两轮的连续单步误差观测阶约2.743／4.857／4.892。理论上初始慢切线余项从 O(t²)起，首个修正可获得经典 O(H⁵)连续单步误差；第二轮不因此自动升阶。实际检查使用内层1e-12，且独立修改方程参考核对曲线。该结果不是任意大 H‖J‖ 的刚性统一阶，也不能将 Radau 三次内部多项式无条件称为高阶连续扩展。

保留了强刚性标量反例：非负原系统含1000倍二次消耗时，一轮曲线连续非负且内层1e-12，H=.1终点仍与独立完整真解相差超过.05。正性、很紧的内层容差或经典阶数不能替代外部实际误差审计。

## 前瞻登记、失败与复核

四个旧开发状态、H=.01／.03，共八区间。Teusink起点 t=1／.001，大模型 t=.1／.001；不是未见过的留出集。两模型各两个固定快组阈值，零／一／两轮修正，内层1e-6／1e-8，共96个候选；48个成熟完整 Radau 对照使用相同梯度信息、排序优化、三个容差与自动／整步起步。所有候选／对照都是单次开发计时，未采用正式七次重复名称。

每区间重新求完整原 ODE 的1e-12／1e-11收紧对，与旧独立参考交叉比较。65点加原公共输出的查询网格保持不变，最大参考差异约.001514个开发严格单位，低于.05。评分同时保存原正式浓度／单向通量1e-3、1e-5与大模型净通量1e-3，以及各自.1的局部接受尺度；后者严格档对应浓度／通量1e-6、净通量1e-4。池和适用物理／修改账本均维持1e-10。

初始序列在首条候选完成后遇到保存接口错误：`Polynomial` 曲线被交给要求 `DensePower.coefficients` 的封装器，尚无任何 runs 保存。原源码、登记、首个参考、日志及明确 `implementation_failure` 元数据完整保留在 [初始归档](../results/m3-slow-tangent-initial/failure.json)，排除科学和计时比较。随后独立新登记改为 InnerCurve原生 pack/unpack，数值内核和六项检查未改；新登记显式引用旧失败归档，没有覆盖或伪造初始运行。

新96个候选中24个因内部负状态拒绝，均来自较早 Teusink 状态；48个完整对照中6个整步起步配置因内部负状态拒绝。失败全部保留，不计合格覆盖或加速。完整数组重算包括端点、拼接、连续非负、实际误差、物理收支、反应阶段、余项、forcing和最终修改账本，122个 NPZ 的 CRC通过。

独立补充核验另存登记与指纹：96+48个精确配置身份全集、264个时间量有限非负且求解时间为正、适用候选必须有两套账本字段、72个完整阶段速率数组，以及144条预测／修正曲线的正性与两账本重建。24个候选失败和6个对照失败原样进入完整性结果；前置物理账本只是诊断，最终决定按原门槛复核。

成熟集合本批只含Radau，缺少匹配CVODE／BDF容差搜索，因此任何正结果仍不能直接晋级；已有更快且合格的完整对照足以否决本实现的本地成本前景。加入本批实际重新求解的高精度参考对只会更慢，但不能把这对参考的耗时当作所有合法单条运行时审计的最低成本。
