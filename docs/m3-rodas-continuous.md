# M3：一次完整分解的 Rodas 连续慢驱动

2026-11-08。**推导并验证了九阶段四次连续驱动，修复了一类混合阶插值的池漂移，但仍没有达到 M4 的效率准入条件。** 原窗口、两原精度档、覆盖率、七次正式重复、相对最快合格成熟基线 1.5 倍中位加速及完整安全审计均保持不变。

## 1. 来源与方法边界

[上一轮配点修正](m3-collocation-correction.md) 能恢复较大宏步精度，却叠加了完整预测、快积分及额外完整分解。本轮转向同一完整 LU 支持更多阶段的 Rosenbrock 连续驱动。

重新阅读 Günther／Sandu，*Multirate Linearly-Implicit GARK Schemes*，[arXiv:2102.10203](https://arxiv.org/abs/2102.10203) v1 的式 2.11、10.6 及 Example 7。原文给出 Rodas 的四阶端点多速率耦合，但不由此推断本项目实际输出曲线具有四阶连续精度。

Rodas4 的六阶段系数来自 SciML `OrdinaryDiffEqRosenbrockTableaus` 源码，固定 Git blob `f1229035a7a4fb21049c6e7329b3e99fdeceeebd`。同时核对执行代码的阶段 RHS、移位矩阵及最终权重。源码系数节选、取用位置和来源见 `results/m3-rodas-continuous/source-coefficients.txt`、`sources.json`；保留 MIT 版权许可于 `research/licenses/OrdinaryDiffEq-Rodas.md`。作者网站 Fortran URL 返回 200，但实际为 Access Denied HTML，未把它当作源码。

原实现使用 A₀、C₀ 与矩阵 I/(Hγ)−J，γ=.25。本实现转成标准 Rosenbrock 增量形式：

```
Γ=(4I−C₀)⁻¹, α=A₀Γ, b=Γᵀb₀
(I−HγJ)k_i = H f(y+Σ_{j<i}α_ij k_j)+H J Σ_{j<i}Γ_ij k_j
```

测试独立执行原变量方程，并核对六个阶段变换和最终状态；不会仅因为方法名称相同就假定系数约定一致。

## 2. 连续阶条件与阶段数

记 B=α+Γ、c=α1、e=B1。完整／慢增量的四阶 Taylor 树对应以下八行：

```
M = [1ᵀ; eᵀ; (c²)ᵀ; (Be)ᵀ;
     (c³)ᵀ; (c⊙αe)ᵀ; (B c²)ᵀ; (B²e)ᵀ]
M μ(θ) = [θ, θ²/2, θ³/3, θ³/6,
          θ⁴/4, θ⁴/8, θ⁴/12, θ⁴/24]ᵀ
```

这些条件针对当前精确 Jacobian 的弱刚性渐近展开，不是任意近似／陈旧 Jacobian 的 ROW 条件，也不是刚性一致精度定理。

六阶段系数的八行矩阵在保存的浮点系数和 NumPy 默认秩阈值下数值秩为 5；加入目标列后秩为 7，最小二乘最大残差约 .11482。因此这六个已有慢增量不能直接组合出满足该系统的四次连续驱动。这是针对当前表示和给定系数的数值可行性结果，不是所有六阶段方法不可能的定理。

首先解前三阶矩条件，并加入终点权重约束，得到六阶段三次扩展。然后在其内部轨迹上增加阶段，所有新增阶段的 Γ 对角仍为 .25，故复用本宏步已有完整 LU。

在模型实验前，穷举 28 组两新增阶段（八分点网格上的三次预测轨迹采样），没有组满足完整四阶矩条件。接着穷举 112 组三新增阶段（56 组网格位置 × 三次轨迹／简单阶段两种构造），全部满足矩条件；按系数矩阵无穷范数选择三次轨迹上的 θ=.25/.875/1。**这个有限搜索不证明三阶段在所有构造中都是最小增量。**

所选九阶段矩阵行满秩，条件数约 1.1592e4，最大矩残差约 4e−15，系数无穷范数约 18.286。最终多项式 μ(θ)=Σ_{k=1}⁴ μ_k θ^k，μ(1)=[b₁…b₆,0,0,0]；因此不改变原六阶段完整 Rodas 的端点，但扩展了连续慢驱动。九次 RHS／九次线性求解均只用一次完整 J 分解，额外快子求解器的分解照常另计。

八项数值测试覆盖矩条件和数值秩障碍、原变量转换、实际 LU 句柄、冻结线性方程的独立矩阵指数解、含混合二阶导数的非线性反应系统局部连续收敛，以及两种等价变量变换。弱刚性局部连续误差随 H 减半，六阶段三次版本趋近四次下降、九阶段四次版本趋近五次下降。这里报告局部连续行为，不把它替换为真实模型全程／刚性阶结论。

96 个二维强弱耦合冻结线性配置（快率 1e2/1e4/1e6，慢率 1/100，四个 H，两扩展、完整／多速率两模式）没有观察到端点谱半径超过 1+1e−8 或 33 个采样点负值。有限维、有限网格检查不保证一般系统稳定或整个曲线非负；真实候选仍运行完整连续非负检查。

## 3. 直接状态版本的结果与连续池漂移

两模型仍取原未扰动前缀（Teusink t=1、k-ecoli t=.1），固定阈值 3／1。H=.001/.003/.01/.03；六／九阶段、完整／多速率模式，多速率内层容差 1e−6／1e−10，共 48 个候选。每个状态／H 有八个不中断成熟 Radau 对照，含 1e−6、1e−7、1e−8、1e−10 和自动／整步初始步，共 64 个。

独立完整 ODE 双容差参考、原 65 个均匀查询及公共观测、非负、池、物理／修改账本均保留。开发精度 1e−4／1e−6、净通量 1e−4 及账本 1e−10 没有改变。直接状态版本通过宽／严格档的候选分别 31／30。

发现一类可重现的问题：慢非活跃物种带有四次慢积分，而快活跃物种直接使用 Radau 三次插值。这可能使同一个守恒池在区间内部不守恒，即使两端和内部接受状态保持良好。大模型九阶段 H=.003、内层 1e−6 的查询池漂移为 1.09e−10；H=.01 为 1.23e−8，均不能接受。

## 4. 两种变量变换，保留全部失败

先试快反应增量 w：

```
z = y + Q(t) + w，w(0)=0，w′=f_fast(z)
```

Q 是同一条慢驱动积分，w 只在快活跃坐标上非零。重构时所有物种保留 Q 的四次项，因此不需要投影。但强抵消状态下 f_fast 与慢项分别很大，新的内层初始迭代缺少原导数的抵消；记录的 48 个候选中有 28 次被非负域检查拒绝，其他 20 次完成，宽／严格档均只通过 13 个。拒绝的具体迭代阶段和累计内部统计保留；没有放宽 RHS 非负检查。小部分严内层配置也明显变贵。

随后登记仿射平移版本，令 q₀ 为慢驱动在 t=0 的值，只在活跃坐标变换：

```
u = z_active − Q_active(t) + t q₀_active
u(0)=y_active
u′ = f_fast,active(z) + q₀_active
z_active = u + Q_active(t) − t q₀_active
```

初始导数与原修改系统相同，保留快慢抵消；稠密输出重构仍包含共同 Q。它是相同 ODE 的变量变换，误差尺度与数值内部步数会变化，不应期待两个离散解逐位相同。原全程检查和独立参考不变，没有 clipping、参考注入或守恒投影。

仿射版本 48 个试探全部积分完成，宽／严格档通过 33／31。大模型上述 H=.003/.01 的查询池误差降到 5.41e−13／1.37e−12。H=.003 通过严格档；H=.01 在内层 1e−6 时浓度／单向通量误差反而达到约 1.555 倍严格门槛，因此依然拒绝。修复守恒输出不能替代精度检查。

三种版本总计 **144 个候选、192 个完整成熟对照，336 条真实模型记录**。原始失败批次未覆盖或删除；每次失败成本留在记录中。相同完整模式在三批中重复保留，目的是检查修改没有暗中改变完整对照。

## 5. 成本与 M4 判断

小模型 H=.03 的九阶段仿射版本即使浓度／通量已合格，物理收支残差约 1.32e−9，仍超过 1e−10 门槛。大模型 H=.03 的九阶段版本浓度／通量约 72 倍严格门槛；收紧内层容差不能解决主耦合误差。四阶渐近矩条件没有转化为当前强刚性区的大宏步资格。

在仿射版本各局部配置中，九阶段多速率候选相对**本批最快合格不中断 Radau**的最好单次比值约 .684（小模型）／.909（大模型）。六阶段小模型最好 .656，大模型约 1.047；这是单次开发计时，不能解释为统计加速。计时尚未包含生产控制器／累计估计和逐步审计，正式端到端成本只会更多。完整 Rodas 同等构造继续作为对照，不能把它的表现记作分裂覆盖或多速率收益。

因此本轮不启动原完整窗口和七次正式重复，也不启动 PE。它排除了“只增加连续弱刚性阶就足以通过 M4”的当前候选，同时留下共同慢多项式与仿射变量变换作为正确性改进。

## 6. 后续顺序

优先研究强刚性慢耦合误差的来源：区分连续近似误差、阶段刚性阶不足和快慢强耦合，先在目标状态的完整冻结 Jacobian 分区上做局部线性化／非线性差异诊断。二维线性无失稳不代表真实 3003 维稀疏网络的耦合正确，继续增加多项式阶数前应先找出这个差异。

若线性强耦合已限制 H，则优先评估具有相应刚性连续精度的耦合；若主要是非线性慢流变化，才考虑新的导数／阶段修正。任何新格式都需保留共同慢曲线、独立完整审计、同等优化的完整系统对照，以及原 M4 条件。
